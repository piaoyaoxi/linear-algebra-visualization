# 第五章生产对照表

第五章不是四组孤立定义，而是一条连续主线：

> 二次多项式如何被矩阵记录 → 如何通过非退化替换消去交叉项 → 哪些符号信息在合同下唯一 → 怎样严格判定所有方向都为正。

本轮重构的首要原则不是增加控件，而是降低学生理解页面的成本：每一节只保留一个主问题、一个主交互和一条清晰的观察顺序。

| 小节 | section id | 正式讲解重点 | 唯一主交互 | 学生最后应能说出的结论 |
|---|---|---|---|---|
| §1 二次型及其矩阵表示 | `quadratic-matrix` | 二次齐次、交叉项平分、对称化、`CᵀAC` 的来源 | 合同变换桥：选择固定换元和测试向量 | 代数恒等式对任意 C 成立；只有 `det C≠0` 才是非退化换元与合同 |
| §2 标准形 | `quadratic-standard-form` | 标准形、Lagrange 配方法、无平方项的和差替换、成对行列操作 | 配方步进器：一次只显示一个配方步骤 | 最终必须同时验证 C 可逆、交叉项为 0、秩保持 |
| §3 唯一性 | `quadratic-uniqueness` | 实规范形、正负惯性指数、惯性定理、合同分类 | 惯性锁：只调一个剪切参数 h，再切到奇异端点 | 合同可以改变系数和等高线，却不能改变正、负、零方向数量 |
| §4 正定二次型 | `positive-definite` | 五种符号类型、标准形判据、Sylvester 判据、半正定警告 | 参数族 `A(t)=[[1,t],[t,1]]` 的边界实验 | `|t|<1` 正定，`|t|=1` 半正定，`|t|>1` 不定；几何与主子式在同一边界变化 |

## 删除的错误方向

上一版的问题不只是视觉粗糙，而是教学结构错误，因此本轮直接删除：

- 四节之上的第二套 `refinement` 内容和 renderer 覆盖层；
- 一个实验中并列多个标签页、仪表盘和自由矩阵滑块的做法；
- §2 将正交主轴法与教材配方法并列为两条主路线的做法；
- §4 把 Cholesky、反例台和多个视图全部塞进主交互的做法；
- 只显示数值变化、却不告诉学生“先看什么、操作什么、最后说明什么”的交互。

正交对角化、Gram 与 Cholesky 仍作为后续连接保留在正式讲解中，但不抢占本节主线。

## 正式讲解公式排版回归

§4“标准形把定义变成符号检查”曾出现 `d_i>0` 与 `d_i≥0` 竖排并覆盖文字的问题。根因是共享清单把 `li` 设为两列 CSS Grid；文本节点、行内 KaTeX 和后续文本被浏览器拆成多个 grid item，公式落入只有 22px 宽的勾号列。

最终修复：

- §4 这组清单恢复普通行内文字流，勾号改为绝对定位；
- 行内公式取消窄盒、边框、背景和多余宽度限制；
- `d_i>0` 与 `d_i≥0` 强制保持完整行内公式，不允许内部折行；
- `learn.html` 提升该样式的缓存版本，避免浏览器继续读取旧 CSS；
- Playwright 直接测量公式宽高比例、左侧位置与右侧溢出：再次掉入勾号列或变成竖排会立即使 CI 失败。

## 视觉参考如何转化

- 第四章第一节的参考价值不在于复制样式，而在于其教学秩序：标题先提出任务，图形只表达一个关系，预设数量有限，结论直接写给学生。
- 精选 PDF 中的倾斜等高线与主轴图用于 §2 的“原坐标 / 新坐标”直觉，但正交主轴不再成为主实验。
- 二次曲面的符号分类用于 §3 和 §4 的颜色与形状语言；页面不复制原书或 PDF 图像。
- 参考 PDF 与原书页面均不进入公开网站路径。

## 完成定义

- 每节进入交互区后，学生无需先学习界面即可知道当前任务。
- 每个主交互最多只有一个连续参数，其余操作使用有明确含义的有限预设。
- 公式、矩阵、图形和结论必须同步，且结论用完整句子说明。
- 奇异替换必须关闭“合同”结论，但不能错误否定代数恒等式。
- 配方终点必须由数值矩阵验证交叉项为零、替换可逆且秩保持。
- 正定临界族必须准确经过正定 → 半正定 → 不定。
- 三维曲面可以拖动旋转；双曲面对比必须保持联动视角。
- 正式讲解中的行内 KaTeX 不得竖排、覆盖文字或溢出内容区。
- 桌面亮色、桌面暗色、390×844 手机、手机减少动态效果全部通过 Chromium 交互检查。
- 浏览器检查同时覆盖 KaTeX、控制台错误、横向溢出和第四章回归，并保存逐节截图供人工检查。
