## 章节主线

```text
方程组
→ 增广矩阵与等价行变换
→ Fⁿ 中的未知向量
→ 线性组合、相关与极大无关组
→ 秩：独立信息的统一计数
→ rank(A) 与 rank([A|b]) 的可达性判别
→ 特解 + Ker(A) 的解族结构
→ 选学：多项式结式消元
```

## 制作原则

- 数值线性代数统一使用精确有理数，不能以浮点阈值代替严格的秩、相关或有解判定。
- Canvas 只承担几何观察。高维判定必须使用完整坐标，投影必须明确标注。
- 每个实验必须在首屏明确写出“操作任务”和“观察结论”，不能让学生面对一堆控件自行猜测。
- 向量统一使用带明确箭头的有向线段；不得再用“线段加端点圆圈”冒充向量。
- 例题先让学生选择，再展开完整分析；错误选项不能提前泄露答案。
- 学生页面不出现制作进度、占位模块或内部参考资料说明。
- 交互监听器在离开小节时全部清理；Canvas 按设备像素比绘制。

## 浏览器验收线

- 章节总览与 7 个小节路由均可进入。
- 每节包含正式概念、真实交互、代表例题、自测和小结。
- 桌面 1440×1000 与窄屏 390×844 无页面级横向溢出。

- 所有 KaTeX 已渲染，无生 LaTeX、无 `.katex-error`。
- 切换小节后旧监听器不再响应，不产生重复绘制或控制器泄漏。

- §4 示例中的非零子式必须确实为非零；所有交互证书由精确计算产生。
