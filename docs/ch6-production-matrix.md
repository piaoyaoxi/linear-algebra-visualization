# 第六章制作矩阵

> 内部制作与验收记录。学生页面不展示本文件。  
> 参考：`chapter6-visualization-production-blueprint.md` 与 97 页精选参考 PDF。参考资料只用于研究，不进入公开站点。

## 全章教学主线

```text
集合与映射
→ 在集合上规定加法与数乘
→ 用基、维数和坐标建立有限描述
→ 更换基但保持对象不变
→ 在大空间中识别子空间
→ 研究交、和与维数账本
→ 用覆盖与零交得到唯一分解
→ 用同构识别相同线性结构
```

## 分节制作矩阵

| 小节 | 核心问题 | 交互实验 | 数学边界与修复 | 完成度 |
|---|---|---|---|---|
| §1 集合·映射 | 一个对应何时是映射，何时可逆？ | 可变基数映射构造器；不完整、单非满、满非单、双射、碰撞预设；原像与逆映射 | 修复旧版等势有限集无法构造“单射非满射”的矛盾；先判合法再判单满双 | A |
| §2 线性空间定义 | 哪些运算结构满足线性空间公理？ | 统一线性组合封闭性实验；二维集合与三通道 RGB 检查 | RGB 明确使用 `[0,1]^3`，只作反例；样本通过不代替证明，一个反例足以否定 | A |
| §3 维数·基与坐标 | 需要多少独立方向，坐标为何唯一？ | 三向量生成组开关、去冗余、维数、基判定、有序基交换与坐标解析 | 修复旧版只有两个向量、无法执行“从冗余生成组删到基”的任务 | A |
| §4 基变换与坐标变换 | 同一向量为何有不同坐标？ | 黄金实验：被动换基与主动变换分栏；基退化门槛；坐标往返 | 修正例题 `P_{W←U}=W^{-1}U=1/2[[1,2],[-1,0]]`；主动模式不再显示过渡矩阵 | A |
| §5 线性子空间 | 子集何时继承线性结构？ | 直线平移、齐次/非齐次平面、象限、`P₂` 线性/仿射约束判定 | 统一使用含零、加法、数乘/线性组合判定；修正“非负卦限”措辞 | A |
| §6 子空间的交与和 | 公共方向与合成范围怎样计算？ | `R²/R³/R⁴` 五类维数情形；二维向量混合器；维数账本 | 代表例题补出精确交空间及和空间基，不只给维数结论 | A |
| §7 子空间的直和 | 何时存在唯一分解？ | 覆盖闸门、零交闸门；非正交、正交、覆盖非唯一、零交未覆盖四类 | 修复旧版“破坏唯一性”预设仍保持线性无关的 bug；分开“存在”与“唯一” | A |
| §8 线性空间的同构 | 外表不同何时结构相同？ | 实算运算保持；坐标同构、线性投影、非线性平方规则对照 | 明确“同维数保证存在同构”不等于“任意映射都是同构” | A |

## 全章硬规则

- RGB 颜色立方体不是实数域上的线性空间。
- 纯换基中几何向量固定；主动线性变换才移动向量。
- 子空间必须含零并对任意线性组合封闭；不过原点的直线、平面属于仿射集合。
- `U+W={u+w}`，一般不等于 `U∪W`。
- 直和要求覆盖与零交，等价于唯一分解；不要求正交。
- 有限维同数域空间同构当且仅当维数相同；具体同构仍须线性且双射。
- 没有真实视频源时只保留 `videoPlan`，学生页面不显示空视频模块。

10. 亮色、暗色、`1440×1000`、`390×844`、`prefers-reduced-motion` 无控制台错误与页面级横向溢出。
