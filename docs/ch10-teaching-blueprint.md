# 第十章教材化重构蓝图

> 内部教学文档。用于维护内容来源、定理主线和可视化分工，不进入学生页面。

## 1. 章节任务

第十章回答四个递进问题：

1. 一个向量怎样被线性地读取成标量？
2. 所有线性读取器怎样组成对偶空间？
3. 一个向量怎样为另一个向量选择读取器？
4. 交错且非退化的配对怎样迫使方向成对出现？

对应的对象链为：

~~~text
f: V → F
→ V*
→ B: V × W → F
→ (V, ω)，其中 ω 交错且非退化
~~~

| 小节 | 主要教材 | 采用的教学结构 |

- *Linear Algebra and Learning from Data* 可为“矩阵每一行都是测量器”提供应用背景，不承担本章定义。

## 3. 每节的证明主线

### §1

~~~text
线性条件
→ f(0)=0
→ ker f 是子空间
→ 非零 f 的像空间是一维
→ dim ker f = dim V − 1
→ 每个非空等值集都是 ker f 的平移
→ 基上的 n 个读数唯一决定 f
~~~

### §2

~~~text
需要读取斜基坐标
→ v^i(v_j)=δij
→ x=Σv^i(x)v_i
→ f=Σf(v_i)v^i
→ V* 由全部读取器组成
→ T*(g)=g∘T
→ (S∘T)*=T*∘S*
→ J(x)(f)=f(x)
~~~

### §3

~~~text
固定一槽得到线性函数
→ aij=B(e_i,f_j)
→ B(x,y)=Σx_i aij y_j=xᵀAy
→ 两空间换基 A'=PᵀAQ
→ 同一空间同一基 A'=PᵀAP
→ 左右根与 ker Aᵀ、ker A
→ 对称—斜对称分解（char F ≠ 2）
→ Q(x)=B(x,x) 只看见对称部分
~~~

### §4

~~~text
ω(x,x)=0
→ 交换输入变号
→ 非退化保证 e₁ 有搭档 f₁
→ 归一化 ω(e₁,f₁)=1
→ V=span{e₁,f₁}⊕span{e₁,f₁}^ω
→ 在辛正交补递归
→ 得到辛基、偶数维和标准 J
→ 保持条件 SᵀJS=J
~~~

“奇数阶斜对称矩阵行列式为零”保留为偶数维结论的快速代数核对；构造辛基是主要证明。

## 4. 可视化与正文分工

- §1 核与等值层：让学生观察沿层移动、跨过核、改变倍率。
- §2 斜基读取器：让学生亲手验证 v¹(v₁)=1、v¹(v₂)=0 及坐标重建。
- §3 固定一槽：让学生观察第二个向量怎样改变协向量的等值层。
- §4 有向面积：让学生比较交换、共线、剪切与均匀缩放。

每节只保留一个核心交互。定义、证明和高维边界使用静态结构与分步例题承载，避免让多个按钮实验争夺注意力。

## 5. 术语与边界

- 本章标量域记为 F；涉及除以 2 的分解和极化时明确假设 char F ≠ 2。
- B:V×W→F 的一般换基是 PᵀAQ；PᵀAP 专指同一空间两槽使用同一新基。
- 协向量的系数列可在选定标准内积后画成法向量；该法向量是坐标代表，不是协向量的无选择定义。
- dim V=dim V* 只给出同构的存在；V→V* 通常依赖基或内积，有限维求值映射 V→V** 具有自然性。
- 二维中 Sp(2,F)=SL(2,F)；高维 det S=1 只是辛性的必要条件。
