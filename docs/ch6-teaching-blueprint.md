# 第六章“线性空间”教材重构蓝图

> 内部教学与实现文档。学生页面不显示来源页码、制作状态或实现说明。

## 1. 本章承诺

本章保留既有八个小节名称，同时用一条连续的定理链组织内容：

```text
完整映射
→ 集合、数域与两种运算
→ 线性组合与张成
→ 相关性引理删除冗余
→ 基的唯一表示定理
→ 所有基等长与维数
→ 有序坐标与换基
→ 子空间判定
→ 交、和与维数公式
→ 直和的唯一分解
→ 基到基的同构与维数分类
```

学生完成本章后，应能回答六个问题：

1. 向量空间为什么必须同时说明数域与运算？
2. 线性相关怎样转化成一条可以删除生成元的规则？
3. 为什么基等价于每个向量有唯一表示？
4. 过渡矩阵为什么是 `W⁻¹U`，其每一列表示什么？
5. 交、和、直和分别解决共同方向、合成范围与唯一分解中的哪一个问题？
6. 为什么同一数域上的有限维空间同构当且仅当维数相同？

## 2. 四幕结构

### 第一幕：什么结构允许线性组合（§1—§2）

- §1 建立映射的完整语言：定义域、陪域、规则、像、原像、单射、满射与逆。
- §2 把线性空间定义成集合、数域、加法和数乘组成的结构；由公理推出基本性质。

### 第二幕：怎样建立可靠坐标（§3—§4）

- §3 从张成进入相关性引理，再由基的唯一表示定理建立维数与坐标。
- §4 固定向量，推导有方向的过渡矩阵，并区分主动变换与被动换基。

### 第三幕：怎样组织空间内部结构（§5—§7）

- §5 使用非空与线性组合封闭判定子空间，并建立 span、齐次条件和交空间三类来源。
- §6 用拼接基求和、用 `B_Ua=B_Wb` 求交，再由基扩充证明维数公式。
- §7 将覆盖与零交合成唯一分解，并推广到多个子空间的零分解判据。

### 第四幕：怎样识别相同线性结构（§8）

- 线性同构必须同时保持线性组合并且双射。
- 线性映射由一组基上的像唯一决定。
- 把基映到基构造同构，最终得到有限维空间的维数分类。

## 4. 八节“问题—操作—结论”矩阵

| 小节 | 起点问题 | 交互承担的观察 | 正式结论 |

| §7 | 分解何时存在且唯一？ | 分开检查覆盖与零交，并拖动公共方向参数 | 二空间零交判据与多空间零分解判据 |
| §8 | 不同类型的元素何时结构相同？ | 比较坐标桥、投影和非线性平方规则 | 基映到基构造同构；有限维同构由维数分类 |

## 5. §2 与 §5 的明确分工

旧内容在两节重复使用过原点直线、仿射直线、象限和常数项约束，导致两节承担同一问题。本轮按以下边界重写：

- §2 的对象是“一整套候选结构”。核心问题是数域、加法和数乘是否已经定义良好并满足八条公理。
- §5 的对象是“已知线性空间 V 的子集 U”。核心问题是 U 能否继承 V 中现成的运算。
- §2 重点使用函数、矩阵、多项式与复数数域展示抽象统一性。
- §5 重点使用 span、齐次条件、任意交和仿射平移展示子空间的自然来源。
- 两节的实验可以共享少量边界场景，但正文、例题和证明任务不得重复。

## 6. 代表例题梯度

每节只保留一道代表例题，并让它承担完整推理：

1. §1 从有限映射表同时读取值域、原像、单满性与复合。
2. §2 证明全体实函数构成向量空间，并用 `f(0)=1` 制造仿射反例。
3. §3 在 `P₂` 中用相关关系删除冗余，再计算非标准基坐标。
4. §4 精确计算 `P(W←U)`，并用两条恢复路径核对同一向量。
5. §5 把 `p(1)=0` 转成 `(x−1)P₂`，由因式分解得到基、维数与坐标。
6. §6 在 `ℝ³` 中联立两种基表示，写出交与和的具体基。
7. §7 将一条直线与一个平面组成直和，并求目标向量的唯一分解。
8. §8 对非标准多项式基写出坐标同构及其逆映射。

每道例题都附带机器可校验的 `example.audit` 数据，避免坐标、基、交空间和过渡矩阵在后续改写中漂移。

## 8. 数学验收边界

- 映射的合法性先于单射、满射与双射判断。
- 数域与运算必须作为线性空间数据明确出现。
- 二维面积只作线性无关的局部直觉，正式定义使用零线性组合。
- 维数只能在所有基等长之后定义。
- `P(W←U)=W⁻¹U`，其第 j 列必须解释为 `[u_j]_W`。
- 子空间判定必须包含非空条件，避免空集的真空封闭。
- `U+W` 是包含 `U∪W` 的最小子空间；一般不等于集合并。
- 求交必须把系数解代回实际向量，不能只报告辅助齐次方程的解。
- 二子空间直和要求覆盖与零交；三个以上子空间不能用两两零交替代零分解判据。
- 有限维同构判据必须写明同一数域；一个具体映射仍需验证线性与双射。
- 一般线性同构不自动保持长度、角度或正交性。
