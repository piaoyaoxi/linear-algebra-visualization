# 第七章制作矩阵

## 全章主线

```text
线性定义
→ 运算与复合
→ 选基后的矩阵
→ 特征方向
→ 对角化
→ 核与像
→ 不变子空间
→ Jordan 链
→ 最小多项式
```

第七章的重点不是重复第四章的网格变形，而是让学生逐步看见一个线性算子的内部结构。每节交互必须回答一个明确问题，并保持图形、矩阵、公式、维数与结论同步。

## 最终制作表

| 小节 | 核心问题 | 最终交互 | 数学边界 | 验收重点 |
| --- | --- | --- | --- | --- |
| §1 线性变换的定义 | 怎样严格判断一个映射是否线性？ | 加法与数乘双路径检验台 | 同一数域；两条线性条件缺一不可；平移保持直线仍非线性 | 路径终点、误差向量与判定同步；投影通过、平移/平方/绝对值失败 |
| §2 线性变换的运算 | 和、数乘、复合与逆分别表示什么？ | 算子混合器：`T+S`、`cT`、`TS`、`ST` | 和要求同型；复合要求类型匹配；乘积逆序 | 同一输入贯穿全过程；`TS` 与 `ST` 顺序明确且可对照 |
| §3 线性变换的矩阵 | 为什么换基只改变记录，不改变变换？ | 同一几何向量的多基坐标翻译器 | 域基与陪域基要区分；相似变换方向一致 | 几何向量固定；坐标、基矩阵与 `P^{-1}AP` 同步；退化基被禁止 |
| §4 特征值与特征向量 | 哪些方向经过变换后仍留在原直线上？ | 单位圆方向扫描器 | 零向量不是特征向量；实数域可能无实特征方向 | 可连续扫描并显示共线误差；90° 旋转明确无实特征方向 |
| §5 对角矩阵 | 什么时候能找到一组特征基？ | 对角化工作台与幂次播放 | 可对角化当且仅当存在特征向量基；重根不自动失败 | 成功与 Jordan 失败案例并列；列交换后 `P,D` 同步；幂次结果正确 |
| §6 值域与核 | 哪些输入丢失，哪些输出可到达？ | 输入—输出双空间实验 | `ker T` 与 `im T` 是子空间；秩—零化度定理 | 满秩、投影、秩一、零映射四类状态正确；核线与像线不混用 |
| §7 不变子空间 | 一个子空间怎样在变换下留在自身内部？ | 候选子空间不变性闸门 | `T(U)⊆U`；特征直线只是特殊情形；限制算子需先过闸门 | 适配基矩阵的左下块与几何判定一致；零空间和全空间始终通过 |
| §8 Jordan 标准形介绍 | 特征向量不足时怎样组织剩余结构？ | Jordan 链传送带 | 在特征多项式分裂的假设下讨论；链由 `N=T-λI` 推进 | `J₂`、分裂块、`J₃` 对照；链顺序与幂零指数正确；不把普通运动箭头当链箭头 |
| §9 最小多项式 | 哪个最低次数多项式能消掉整个算子？ | 多项式消算子实验 | 首一、最低次数、非零；整除特征多项式；平方自由判据 | 候选多项式在整个算子上验证，不只测一个向量；Jordan 块次数正确 |

## 统一学生页面结构

每节包含：概念问题、正式内容、真实交互、代表例题、自测、小结与上下节连接。没有真实视频源时不显示视频模块；不出现开发进度、占位或未来制作语言。

## 工程结构

- `current/content/ch7.js`：九节内容数据与例题、自测、总结。
- `current/visuals/ch7/registry.js`：第七章 renderer 与 enhancer 注册、清理生命周期。
- `current/visuals/ch7/presentation.js`：正式内容和九个交互实验。
- `current/visuals/ch7/presentation.css`：章节专用响应式与主题样式。
- `current/visuals/ch7/mount.js`：只在第七章路由挂载第七章增强器。
- `current/app.js`、`current/learn-entry.js`：将完整小节路由从第四章专用逻辑泛化为任意结构化章节。
- `.github/scripts/ch7-browser-check.mjs`：实际 Chromium 验收。

## 浏览器验收线

- 九个小节独立路由均有正式内容、交互、例题、自测和小结。
- 桌面亮色、桌面暗色、390px 手机端与 reduced-motion 均无页面级横向溢出。
- 所有关键预设和临界状态均由浏览器脚本真实点击或调节。
- 无 console error、page error、资源 404 或 KaTeX 错误标记。
- 路由离开后事件和动画清理；多次往返不会重复挂载。
- 回归检查第四章第一节，原有矩阵解剖和网格交互不被第七章挂载器污染。
