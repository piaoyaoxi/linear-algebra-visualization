# 第八章制作矩阵

> 内部制作与验收记录。精选参考 PDF 只用于研究视觉叙事，不作为网站公开资源提交。

## 全章主线

`A → λI-A → Smith 标准形 → 不变因子 → 初等因子 → Jordan / 有理标准形`

第八章不重复第七章的特征值入门。它回答更深一层的问题：怎样从特征矩阵提取在换基下保持不变的结构指纹，并由这套指纹重建标准形。

## 数学边界

- `F[λ]` 的单位是非零常数；λ-矩阵可逆要求行列式是非零常数。
- Smith 化简只允许可逆的多项式行、列操作，并同步记录左右乘子。
- 多项式矩阵的等价与常数矩阵的相似必须分开表述。
- 不变因子满足整除链；其乘积给出特征多项式，最大不变因子给出最小多项式。
- 初等因子依赖底域上的不可约分解；Jordan 标准形要求特征多项式在底域上分裂。
- 有理标准形在任意域上存在，由不变因子的友矩阵块组成。
- 不以二维网格变形冒充本章结构；核心视觉语言是算法步进、指纹对照、因子拆分与向量链。
