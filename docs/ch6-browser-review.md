# 第六章浏览器截图复核

本文件记录 PR #39 的浏览器复核过程。第六章必须使用项目现有设计系统，不允许另造固定的章节配色或独立的“AI 海报式”SVG 语言。

## 本轮视觉重置

用户否定了上一轮的深蓝舞台、固定青橙配色、发光箭头、虚线大椭圆和圆形节点。本轮不是调色，而是删除整套私有视觉语言：

1. 删除 `--ch6-ink`、`--ch6-cyan`、`--ch6-orange` 及对应固定色值。
2. 删除 SVG 高斯发光滤镜和粗重的装饰箭头。
3. 主画布统一使用项目的 `--surface-solid`、`--surface-soft`、`--line`、`--text`、`--muted`、`--accent` 等主题变量。
4. 集合映射从“大椭圆 + 圆点”重做为两个克制的集合面板、矩形元素节点和细连接箭头。
5. 教学文案从“记住某种颜色代表什么”改为直接说明对象角色：`U`、`W`、`v`、`u+w`、输入、输出和反例。
6. 手机端几何画布放大数学对象本身，而不是保留无意义的坐标空边。

## 对照基准

- 第一章：纸面背景、弱边框、轻量强调与自然留白。
- 第四章第一节：细网格、克制箭头、项目主题变量和清晰的对象—变化—结论叙事。
- 第五章：几何对象直接服务数学含义，不依赖装饰性色洗或发光。

## 逐节复核重点

| 小节 | 本轮重点 |
|---|---|
| §1 集合·映射 | 两个项目原生集合面板；禁止椭圆集合、圆形节点、深色大舞台和固定青橙配色 |
| §2 线性空间定义 | 公理与反例按数学角色叙述；多项式公式完整；不依赖“红色对象”才能读懂 |
| §3 维数·基与坐标 | 面积连续变化；共线预设严格满足行列式为 0；`v₁`、`v₂`、`v₃` 直接标在对象上，不用颜色字典代替说明 |
| §4 基变换 | 标准网格 `U`、新基 `W`、固定向量 `v` 按角色区分；主动与被动过程保持连续 |
| §5 线性子空间 | 原点和反例直接说明失败原因，不要求学生先寻找某种颜色 |
| §6 子空间的交与和 | 固定 `U`、连续转动 `W`；先读公共方向与铺满范围，再看维数账本随夹角同步改变 |
| §7 子空间的直和 | `u`、`w`、`v` 直接标注；目标 `v` 固定，拖动公共方向展示非唯一性 |
| §8 线性空间同构 | 多项式曲线与坐标点同步变化；完整坐标桥、投影压缩与平方折叠直接显示线性、单射和满射分别在哪里成立或失败 |

## 自动拒绝项

`.github/scripts/ch6-source-style-check.mjs` 会递归扫描第六章视觉文件并拒绝：

- 私有固定调色板和旧固定色值；
- SVG 发光滤镜；
- 旧集合椭圆结构；
- “青色：”“橙色：”“白色：”“绿色：”等颜色优先的教学文案。

浏览器脚本同时检查：

- 亮色主题主舞台不得退回深色电影式面板；
- 控件、主画面、结果保持单一阅读轴；
- 公式不碎裂；
- 向量不是“圆点 + 细线”；
- 标签不碰撞、不越界；
- 桌面、暗色、手机与减少动态效果均无横向溢出。
- 画布上方的观察说明必须占独立信息栏，不得覆盖曲线、向量或映射节点。
- §6 重合与分开状态的维数账必须分别为 `1+1−1=1` 与 `1+1−0=2`。
- §8 必须存在可见的多项式—坐标几何桥和三个连续系数控件。
