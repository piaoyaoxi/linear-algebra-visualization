# 第七章最终可视化分镜

> 内部制作资料，不进入学生页面。本文件替代已经废弃的第三轮统一面板方案。

## 1. 视觉与交互基线

第七章不新增独立配色体系。页面只使用项目现有的纸张、墨色、青绿、珊瑚与金色主题变量，并继承成熟章节的边框、圆角、阴影与暗色模式。颜色只区分数学对象，不承担装饰作用。

每节遵循同一条教学顺序，但不复用同一幅构图：

1. 提出唯一核心问题；
2. 让主要几何对象占据实验区；
3. 在控件之前说明具体操作；
4. 通过按钮、滑杆或画布拖动产生连续变化；
5. 用一句完整结论和同步公式解释刚看到的现象。

向量由箭杆与箭头一体的闭合路径绘制，不附加端点圆球。圆点只表示输入样本、空间中的点或共同像。公式不得替代图形应承担的解释任务。

## 2. 九节独立分镜

### §1 线性变换的定义：比较两条计算路径

输入、输出双平面并列。学生拖动 `u`、`v`，依次检查原点、加法与数乘。线性预设中两条路径闭合；平移和绝对值预设直接显示终点缺口。结论来自“是否到达同一点”，不是一组真假指示灯。

### §2 线性变换的运算：对象通过变换机器

输入对象沿横向流程经过 `T`、`S`。逐点相加显示两条并行支路，复合显示输入—中间状态—输出，逆变换显示能否沿路径唯一返回。学生可以连续拖动进度，直接比较 `T∘S` 与 `S∘T` 的顺序差异。

### §3 线性变换的矩阵：从基向量的像生成两列

先只观察 `e₁` 进入变换并生成第一列，再观察 `e₂` 生成第二列。随后用 `x=αe₁+βe₂` 重建 `T(x)`，最后切换基，区分真实几何作用与矩阵记录的变化。

### §4 特征值与特征向量：寻找不转向的直线

同一坐标平面持续显示候选直线、`v` 与 `Av`。学生既可拖动角度滑杆，也可直接抓住方向线旋转。只有非零、共线并能读取伸缩比时才形成特征方向；90° 旋转作为“实数域无特征方向”的边界。

### §5 对角化：把混合运动拆成独立缩放

单一主平面按阶段展示：把向量翻译成特征基分量、分别缩放两个分量、重新合成 `Ax`。`P⁻¹x` 始终被解释为坐标记录而非真实空间中的移动。Jordan 预设在独立特征方向不足处停止。

### §6 核与值域：同一纤维为什么落到同一像

输入空间显示整条 `x+ker(T)` 及其多个样本，输出空间同步显示共同像和值域。拖动纤维参数时，输入样本沿核方向移动而输出不变。满秩、秩一与零变换分别呈现“无非零核”“压到一条线”“全部汇聚原点”。

### §7 不变子空间：检查整个 `W`，不是一支向量

候选方向上取多个 `W` 中样本，并同时绘制它们的像。学生拖动候选方向；任何样本泄漏出 `W` 都形成清楚的距离标记，并与适配基下矩阵左下角是否为零同步。零子空间和整个空间单独说明。

### §8 Jordan 标准形：分离缩放与幂零剪切

先展示特征向量不足导致对角化失败，再比较 `T=λI+N` 中的共同缩放与额外剪切。切换到 `N` 后，学生逐步推进 Jordan 链，看到广义向量沿链传递并最终归零；页面不暗示完整算子 `T` 必然归零。

### §9 最小多项式：候选多项式能否消去整个空间

候选多项式同时作用于一组基方向。每个方向显示残量箭头，零残量严格停在原点，不用散落的叉号伪装。只有所有基方向都归零才得到 `p(T)=0`，随后再比较是否存在次数更低的首一多项式。

## 3. 工程边界

实现由共享数学/绘图原语与九个独立 renderer 组成：

```text
current/visuals/ch7/story.css
current/visuals/ch7/story-core.js
current/visuals/ch7/story-section1.js
...
current/visuals/ch7/story-section9.js
```

共享层只提供坐标平面、向量、网格、结论和事件绑定；每节独立维护构图、状态和叙事。第七章 renderer 通过章节 registry 挂载和卸载，不覆盖第四章组件。

## 4. 验收标准

- 九节逐一操作按钮、连续滑杆与画布拖动；
- 九道代表例题逐一提交正确答案并检查反馈；
- 桌面亮色、桌面暗色、390px 手机端和 reduced-motion 逐节截图；
- 检查公式、裁切、标签遮挡、对比度、横向溢出和控制台错误；
- 回到第四章第一节做组件隔离与布局回归；
- 自动检查通过后仍需人工查看截图与公开预览。

CI 是最低线，学生进入实验后十秒内知道“看什么、拖什么、变化意味着什么”才是完成线。
