# 第二章“行列式”教学重构蓝图

> 内部教学与实现文档。学生页面不显示来源页码、制作状态或实现说明。

## 1. 本章承诺

本章保留北大版《高等代数》第二章八个小节的顺序，同时用一条可追踪的论证主线把它们连起来：

> 行列式是满足单位归一、分别线性与交替性的唯一标量函数；几何上，它记录有向面积或有向体积的倍率。

学生完成本章后，应当能够回答五个问题：

1. 为什么二阶公式是 `ad-bc`，负号记录了什么？
2. 为什么高阶公式只允许“每行、每列各取一次”，项前为什么出现排列符号？
3. 为什么交换、倍乘、倍加、三角形行列式等规则来自同一个结构？
4. 面对一个具体行列式，怎样在消元、展开与直接读结构之间选择路线？
5. Cramer 法则、Laplace 定理和乘法规则如何从前面的结构生长出来？

## 2. 三幕结构

### 第一幕：这个数记录什么（§1—§3）

- §1 从有向面积提出问题，区分倍率、定向与塌缩。
- §2 解释“交换一次就翻转一次符号”，把排列奇偶性变成一致的符号账本。
- §3 用每行每列各取一次的路径定义 n 阶行列式，并说明三阶公式只是一般定义的一个展开。

### 第二幕：为什么这些规则能计算（§4—§6）

- §4 用 `det(I)=1`、分别线性、交替性统领全部性质，并回看 §3 的公式为何并非任意规定。
- §5 把计算变成路线选择：先识别结构，再选消元、展开或直接读取。
- §6 把 Leibniz 求和按一行或一列分组，推导代数余子式展开，而不是只记“划掉一行一列”。

### 第三幕：这个数能解决什么（§7—§8）

- §7 用列线性推导 Cramer 法则，分别处理唯一解、无穷多解与无解；病态敏感性放在深入层。
- §8 分成两个清楚的阶段：多行 Laplace 展开与复合变换的倍率乘法。

## 4. 八节的“问题—操作—结论”矩阵

| 小节 | 起点问题 | 学生先做的操作 | 操作后形成的结论 |
| --- | --- | --- | --- |
| §1 | 哪个数能同时记录大小、方向与塌缩？ | 预测剪切、镜像、共线时 det 的状态，再拖动两列 | `|det|` 是面积倍率，符号记录定向，零值记录降维 |
| §2 | 一项乘积的正负号怎样不依赖交换路线？ | 先预测一次相邻交换的奇偶变化，再扫描逆序对 | `sgn(σ)=(-1)^τ` 是一致的符号账本 |
| §3 | n 阶公式为什么每项只取 n 个元素？ | 先判断重复取列的项是否可能保留，再选合法路径 | 仅排列路径合法；每项带排列符号 |
| §4 | 哪几条规则足以决定全部行列式？ | 先预测交换、倍乘、倍加对 det 的影响，再看几何对照 | 归一化、分别线性、交替性统一派生规则 |
| §5 | 面对一个行列式，第一步该做什么？ | 先选路线，再执行消元并维护倍率账本 | 结构识别先于运算；主元乘积是通用计算主线 |
| §6 | “划掉一行一列”为何给出正确展开？ | 先选最省项的方向，再追踪一个元素对应的项组 | 余子式展开是 Leibniz 求和的分组 |
| §7 | 替换一列为何能读出一个未知量？ | 先判断 `D=0` 能否直接分类，再比较 `D,D1,D2` | `D≠0` 给唯一解；`D=0` 还需继续判定 |
| §8 | 多行展开与复合倍率有什么共同结构？ | 先配互补子式，再预测两阶段倍率 | Laplace 组织互补选择；`det(AB)=det(A)det(B)` |

## 5. 页面内容标准

每节只保留以下必需层级：

1. 一个学生能复述的主问题。
2. 两到三个承担论证的正文模块。
3. 一个“先预测再操作”的真实交互。
4. 一个需要计算、构造或补全理由的代表例题。
5. 四道自测：概念、计算、解释、迁移各一题。
6. 小结只回答“本节新增了哪一步，怎样接到下一节”。

正文与视觉的文字只在 `current/content/ch2-section*.js` 维护。`current/visuals/ch2/` 读取这些数据并负责布局、状态与绘图，不再另写一套正式讲解。

## 6. 数学与呈现验收

- §4 明确出现 `det(I)=1`，且说明缺少归一化不能唯一确定行列式。
- §3 合法项、排列符号与上三角结论之间有完整推理。
- §5 至少比较三条计算路线，不把单一路线演示成唯一方法。
- §6 明确说明余子式展开来自项的分组。
- §7 不把 `D=0` 直接等同于无解或无穷多解。
- §8 将 Laplace 与乘法规则分成两个视觉和阅读阶段。
- 所有代表例题先保留题目，学生作答或点击步骤后才显示解析。
- 桌面与 390px 手机宽度无横向溢出，八节无脚本或控制台错误。
