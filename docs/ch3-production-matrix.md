# 第三章制作矩阵

> 内部制作与验收文件，不进入学生正文。
> 最后更新：2026-08-10

## 章节主线

```text
方程组
→ 增广矩阵与等价行变换
→ Fⁿ 中的未知向量与 Ax 的列组合
→ 表示唯一性、线性相关与极大无关组
→ 秩：独立信息的统一计数
→ rank(A) 与 rank([A|b]) 的可达性判别
→ 特解 + Ker(A) 的解族结构
→ 选学：多项式结式消元
```

## 制作原则

- 页面顺序统一为“概念问题 → 几何直觉 → 定理与结构 → 精确实验 → 例题与自测”。先建立可见对象，再引入形式化语言。
- 核心几何叙事采用与第四、第五章相同的主题变量、细线坐标系和高分辨率 Canvas；精确计算、RREF、完整坐标和参数验证收进默认折叠的精确实验。
- 不使用与参数脱节的装饰性位图，也不使用独立于项目的深色舞台。第三章的向量、子空间、网格变换和解族都随步骤或参数实时变化。
- 数值线性代数统一使用精确有理数，不能以浮点阈值代替严格的秩、相关或有解判定。
- 低维 Canvas 只承担几何观察。高维判定必须使用完整坐标，投影必须明确标注。
- 每个视觉实验必须明确“当前看什么、为什么变化、最终读出什么结论”，不能让学生面对一堆控件自行猜测。
- 向量统一使用带明确箭头的有向位移；不得再用“线段加端点圆圈”冒充向量。
- 颜色承担稳定语义：主对象、第二方向、合成/目标对象在同一小节内保持一致，不为装饰随意换色。
- 例题先让学生选择，再展开完整分析；错误选项不能提前泄露答案。
- §2—§6 复用 `docs/ch3-teaching-blueprint.md` 中的 3×4 贯穿矩阵；低维视觉负责观察，完整坐标负责严格验证。
- 每个定量例题保留不渲染的 `audit` 数据，并通过 `tests/ch3-content-audit.cjs` 验算。
- 学生页面不出现制作进度、占位模块或内部参考资料说明。
- 交互监听器在离开小节时全部清理；Canvas 按设备像素比绘制并在视口变化时重绘。

## 从成熟章节提取的视觉系统

- 背景与容器：使用课程既有的暖白页面、白色实体卡片、浅薄荷辅助面与 1px `var(--line)` 边界；不新增深蓝底、发光边框或装饰渐变。
- 文字层级：沿用课程的大号衬线章节标题、黑色小节标题、灰色正文与绿色小标签；数学公式进入浅薄荷公式面板，不压在图形上。
- 色彩语义：`var(--accent-strong)` 表示已有结构或第一方向，`var(--coral)` 表示第二方向或正在变化的分量，第四章既有的 `#547ec8` 表示目标或当前对象。
- 几何线条：网格和坐标轴为细线，向量使用 2—2.4px 箭身与常规三角箭头；禁止闭合粗棒箭头、发光描边和厚重 span 色带。
- 交互节奏：一个核心问题对应一个连续画布；步骤按钮或滑杆只改变这一场景中的数学对象，右侧同步解释“当前变化—公式—结论”。
- 响应式：桌面为画布与解释并排，窄屏改为上下排列；按钮自动换行，公式面板可容纳两行推导，页面不得产生横向滚动。

## 全章几何叙事

| 小节 | 连续画布 | 精确实验保留内容 | 数学不变量 |
| --- | --- | --- | --- |
| §1 | 共同交点 → 可逆倍加 → 主元结构 | 三类行操作、阶梯形、RREF、撤销 | 行等价不改变解集 |
| §2 | αu 缩放 → βv 首尾相接 → 读出合向量 | n=1—8、完整坐标、分量条、列组合权重 | w=αu+βv 逐坐标同步 |
| §3 | v₁ 张成直线 → v₂ 扩成平面 → v₃ 留在旧 span | 拖动、两套表示、非平凡零组合、删除测试 | 新向量在旧 span 中则表示不唯一且维数不增 |
| §4 | 2×2 看面积/直线/点；3×3 看体积/平面/直线 | RREF、主元列、非零子式、行操作 | rank 是像空间维数 |
| §5 | b 在线上 → 拖离 Col(A) → 标出不可达分量 | 增广矩阵、RREF、矛盾行 | rank(A)=rank([A|b]) iff solvable |
| §6 | x₀ 锚定解线 → 沿 η 移动 → 全部输入映到同一 b | 特解切换、参数、双重验证 | Ax=b 且 A(x−x₀)=0 |
| ＊§7 | 看交点 → 投影 x 轴 → 形成结式 → 回代 | 相交/相切/无实点、x/y 消元 | 候选必须回代原方程 |

## 浏览器验收线

- 章节总览与 7 个小节路由均可进入。
- 每节的几何直觉位于定理与结构之前，精确实验默认折叠但可以完整打开操作。
- 桌面 1440×1100 与窄屏 390×844 无页面级横向溢出。
- 亮色、暗色与 prefers-reduced-motion 均可使用。
- 所有 KaTeX 已渲染，无生 LaTeX、无 `.katex-error`。
- 每个步骤按钮或滑杆、字幕、公式和图形状态同步；移动端保留一个完整大画布，不把数学对象压缩成多个缩略图。
- 矩阵、标签、箭头和说明框必须处于设计位置；滑杆极值、暗色主题与窄屏下不得重叠或裁切。
- §2 的 αu、βv 与 w 必须能直接读出首尾相接关系，标签不得互相覆盖；滑杆极值下也不得裁切。
- §3 的 v₃ 必须同时有非平凡线性关系和“删除后 span 不变”的几何解释。
- §4 的网格必须明确呈现二维面积、一维直线和零维点三种输出。
- §5 的 b 必须以目标向量显示，而不是孤立点。
- §6 必须清晰区分 O→x₀、x₀→x 的零空间位移和 O→x，并显示所有解映到同一个 b。
- §7 候选点在完成回代前不得标为已验证解。
- 精确层继续使用完整维度和精确有理数，不得用低维 SVG 投影替代严格结论。
- 回归检查第一章、第四章、第五章的当前 main 实现仍保留，第三章分支不得回退它们。
