## 制作规则

- 学生页面只显示已经成立的内容：真实视频、真实交互、正文、例题、自测和小结。
- 短片可选。只有存在真实 `video.src` 或 `video.embed` 时，页面才显示“概念短讲”。
- 未来短片脚本放在 `videoPlan` 或文档中，不进入前台视频模块。
- 交互可选。只有学生能通过操作回答一个明确问题时，才保留交互。
- 第四章先做 §2 样板，再按依赖补 §3、§4、§6，最后处理 §5、§7。
- 各节只承担自己的核心问题：前一节已经建立的判定或直觉，后一节只作必要引用，不重新讲一遍。

## §2 样板验收线

§2 完成后，应当成为后续小节的模板，但后续小节不强制复制全部模块。

- 起点问题能说明“为什么乘法不是逐项乘”。
- `videoPlan` 有完整 1—3 分钟短片脚本，但没有真实视频源时前台不显示视频。
- 连续复合使用同一张网格与同一个输入对象，真实播放 `I → B → AB`，并可与一次完成的 `I → AB` 对照。
- 列视角让 `b_1,b_2` 连续移动为 `Ab_1,Ab_2`，颜色在全过程保持一致。
- 行乘列点击结果元素后，配对项依次高亮并汇入求和。
- `AB` 与 `BA` 从同一初始方格同步播放，明确显示不同的中间状态和最终结果。
- 定理概念同时给出尺寸条件、行乘列公式、单位矩阵、结合律和通常不可交换。
- 代表例题折叠显示，至少分 5 步：查尺寸、算 `AB`、算 `BA`、解释顺序、提炼结论。
- 自测覆盖尺寸、作用顺序、列解释、元素公式和不可交换。
- 小结包含本节主线、下一节连接和常见误区。

## §3 验收线

- 两列拖动、滑块、矩阵、平行四边形、行列式、秩和可逆状态必须同步。
- 行列式可以连续逼近 0；只要仍非零，二维秩必须保持为 2，到精确临界状态才下降。
- 镜像预设应明确区分面积绝对值与行列式符号。
- `AB` 与 `BA` 使用同一对矩阵同步播放：最终形状可以不同，但行列式与面积倍率相同。
- 固定秩 1 的 `B` 后，可逆 `A` 必须保持 `rank(AB)=1`；不可逆 `A` 可以让秩继续降到 0。
- 转置交互应交换行列结构，并保持秩不变。
- 代表例题应同时使用乘积行列式和可逆因子保持秩，避免退化为完整展开计算。

## §4 内容边界与验收线

- 只把 `det(A)≠0`、满秩作为第三节已经建立的可逆判定，不再重复面积、坍缩和秩瓶颈的教学。
- 主线从 `AA^{-1}=A^{-1}A=I` 开始，明确逆矩阵存在时唯一，并说明双侧逆只可能出现在方阵中。
- 讲清 `Ax=b`、`AX=C`、`XA=C` 中逆矩阵应乘在哪一侧。
- 用撤销复合过程解释 `(AB)^{-1}=B^{-1}A^{-1}`，不重做第二节的矩阵乘法教学。
- 2 阶求逆公式必须同时写出分母非零的限制。
- 用 `AX=I` 说明逆矩阵各列满足 `Ax_j=e_j`；初等行变换的通用算法留到 §6。
- 不展开一般 n 阶伴随矩阵公式，不进入伪逆、最小二乘或正交矩阵专题。
- 代表例题同时完成“求逆—解方程—代回验证”的闭环。
