## 1. 全章教学主线

本章不是九个互不相关的专题，而是一条从“映射”进入“内部结构”的连续路线：

```text
线性变换的定义
-> 线性变换的运算
-> 选定基以后得到矩阵
-> 寻找保持方向的向量
-> 在特征基中化为对角作用
-> 研究被压成零和能够到达的部分
-> 研究被变换保留的子空间
-> 特征向量不足时引入 Jordan 链
-> 用最低次数多项式概括整个变换的代数约束
```

### 1.1 三层叙事

- **对象层**：向量、直线、平面、子空间和向量轨道怎样移动。
- **坐标层**：选定基后，线性变换怎样被一个矩阵记录；换基为什么只改变记录方式。
- **结构层**：特征方向、核、值域、不变子空间、Jordan 链和最小多项式怎样揭示同一个算子的内部结构。

### 1.2 全章必须保持的视觉连续性

- 同一向量在不同页面中使用同一基础颜色语义。
- 输入空间与输出空间使用明确、稳定的空间标签，不能只靠左右位置暗示。
- “真实几何对象”和“坐标列向量”必须在视觉上区分，但能通过连线或过渡对应。
- 换基时，空间中的向量和线性变换保持不动，只让坐标网格、坐标数字和矩阵记录改变。
- 特征方向、不变子空间、核和值域使用不同的视觉状态，不能都用同一种高亮直线。
- Jordan 链中每个向量的顺序固定；链上的箭头表达 `(T-lambda I)` 的作用，不表达普通空间移动。
- 最小多项式交互中的“消掉”必须表现为算子作用后归零，不使用删除、淡出等容易造成误解的纯装饰动画。

## 2. 全章统一制作规则

### 2.1 每节页面骨架

每节原则上按以下顺序组织；没有必要的视频模块可以省略，但不能显示空容器：

1. 小节标题、核心问题、学习目标与关键词。
2. 起点问题：先提出需要解释的现象。
3. 直觉引入：真实视频、自动动画或静态对照三选一。
4. 核心讲解：定义、规则、性质和前后连接。
5. 可视化实验：每个交互必须回答一个明确问题。
6. 代表例题：题目默认显示，答案和解析由学生操作后展开。
7. 自测：3-8 道短题，覆盖概念辨析与结构判断。
8. 小结：一句主线、常见误区、下一节衔接。

### 2.2 视频、自动动画与交互的分工

- **讲解视频**：用于存在不可打断的叙事顺序，例如换基、从特征基到对角化、Jordan 链和最小多项式。
- **自动动画**：用于步骤固定、无需学生调参的过程，例如加法平行四边形检验、坐标轴换基、Jordan 链逐级传递。
- **可视化交互**：用于参数边界、临界状态、反例和分类，例如线性/非线性判断、方向扫描、核和值域维数变化。
- **例题**：把视觉直觉落回符号计算和证明，不用大量机械计算替代概念理解。

### 2.3 交互统一规则

- 参数变化后，图形、公式、矩阵、维数和结论同步更新。
- 关键状态必须提供预设按钮，学生不需要手动凑出特征方向、秩下降或 Jordan 块。
- 数值计算必须设置容差，并将“近似共线”和“严格共线”、“近似特征方向”和“真正特征方向”分开表达。
- 交互必须提供一个明确任务和至少两个观察问题。
- 离开页面或切换章节时，取消动画帧、监听器和计时器。
- 支持键盘、可见焦点、屏幕阅读器标签和 `prefers-reduced-motion`。
- 移动端可减少同时显示的辅助图，但不得省略核心数学对象和结论。

### 2.4 公式与术语规则

- 学生页面使用本地 KaTeX。
- 线性变换统一用 `T,S`；矩阵表示统一用 `A=[T]_B` 或带域、陪域基的完整记号。
- “像”“值域”“像空间”必须在全章选定一种主称呼，其余称呼在首次出现时说明。
- `ker T` 与 `im T` 或 `T(V)` 的记号必须与教材一致。
- “特征子空间”“广义特征子空间”“不变子空间”不能混用。
- Jordan 标准形只在教材允许的数域与假设下表述；必要时明确“特征多项式在所讨论数域上分裂”。
- 最小多项式必须定义为首一、次数最低、使 `m_T(T)=0` 的非零多项式。

### 2.5 例题统一规则

- 题目和选项始终可见，解析默认折叠。
- 错误选择给方向性提示，不直接泄露答案。
- 正确后分步展开；每一步只推进一个逻辑动作。
- 每节至少一题要求学生解释“为什么”，不能全部是计算题。
- 解析同时包含符号推导和对应的几何或结构含义。

### 2.6 版权与视觉改造规则

- 精选 PDF 仅供内部研究，不随公开网站或公共仓库发布。
- 不直接截取原书图片放入网站。
- 不逐像素重画原书构图。
- 允许借鉴：数学对象、变量关系、连续变化机制、对比结构和问题顺序。
- 必须重做：配色、布局、图形风格、标注系统、动效节奏、交互控件和例题文案。

# §1 线性变换的定义

## 参考资料

- 精选参考 PDF：第 1-23 页。
- 原书物理页：423-437、500-506。
- 主要用途：`Ax=y` 的输入输出、二维与三维矩阵变换、原点固定、直线与平行结构，以及平移/仿射变换作为反例。
- 参考局限：参考书主要从矩阵作用出发，本节的抽象定义、域与陪域、线性条件仍须依据教材补齐。

## 核心问题

> 一个变换满足什么条件，才配称为“线性”？

## 学习目标

学生完成本节后应能：

- 说清线性变换的定义域、陪域和输出。
- 分别检查加法保持与数乘保持。
- 推出 `T(0)=0` 和线性组合保持。
- 判断平移、绝对值、平方映射等为什么不是线性变换。
- 区分“图形看起来规则”和“满足线性条件”。
- 理解线性变换由一组基向量的像唯一决定。

## 页面讲解顺序

### 1. 开场：同样是“变形”，哪些是线性的

并排展示四个过程：

- 过原点的旋转。
- 缩放或剪切。
- 整体平移。
- 非线性弯曲。

先让学生凭直觉分类，再提示：图形是否好看、网格是否整齐都不是定义；真正标准是加法与数乘是否被保持。

**媒介**：20-30 秒自动动画，不做独立视频。

### 2. 主交互：Linearity Tester（线性检验台）

中央显示候选变换 `T`，左右同时显示两项检验：

- 加法检验：比较 `T(u+v)` 与 `T(u)+T(v)`。
- 数乘检验：比较 `T(cu)` 与 `cT(u)`。

学生可以拖动 `u,v`，调节 `c`，并切换预设：

- 旋转。
- 剪切。
- 投影。
- 平移。
- 分量平方。
- 绝对值折叠。

视觉要求：两条计算路径使用相同终点标记；重合时合并，分离时显示误差向量。不能只显示“通过/不通过”。

### 3. 从两条规则推出线性组合保持

依次显示：

```text
T(a1v1 + a2v2)
= a1T(v1) + a2T(v2)
```

随后推广到有限线性组合。这里为 §3“基向量的像决定矩阵列”埋下伏笔。

### 4. 自动动画：零向量为什么必须留在原点

从 `T(0)=T(0+0)=T(0)+T(0)` 出发，图形中让原点的像被等式“拉回”原点。再把平移放在旁边作为反例。

### 5. 基决定变换

在二维基 `e1,e2` 上设置两个像，随后用滑块生成任意 `x=ae1+be2`，显示：

```text
T(x)=aT(e1)+bT(e2)
```

这里不进入矩阵坐标和换基细节，只建立“知道基的像，就知道整个变换”的事实。

## 代表例题

给出四个映射，让学生判断线性并说明失败位置：

- `T(x,y)=(x+2y,y)`。
- `S(x,y)=(x+1,y)`。
- `R(x,y)=(|x|,y)`。
- `P(x,y,z)=(x,y)`。

解析顺序：明确域和陪域 -> 检查加法/数乘 -> 用一个最小反例否定 -> 说明矩阵能否表示。

## 自测范围

- 线性条件的两个部分。
- `T(0)=0`。
- 线性组合保持。
- 平移与仿射变换。
- 非方阵对应的线性变换。
- “保持直线”是否足以推出线性。

## 验收标准

- 每个预设至少能由一条可见路径展示通过或失败原因。
- 平移必须在原点条件和加法条件上明确失败。
- 投影被正确判断为线性，避免学生把“降维”误判为非线性。
- 本节不提前讲特征值、秩或行列式判据。
- 移动端仍能同时比较两条检验路径。

# §2 线性变换的运算

## 参考资料

- 精选参考 PDF：第 24-35 页。
- 原书物理页：203-213。
- 主要用途：矩阵乘法性质、复合顺序、逆操作、恒等作用和不可交换现象。
- 参考局限：变换加法与数乘需要按教材从函数层面补充，不能只把矩阵运算当定义。

## 核心问题

> 两个线性变换怎样相加、缩放、复合和反向？这些运算为什么仍然保持线性？

## 学习目标

- 定义 `T+S` 与 `cT`，理解其逐点含义。
- 理解复合 `TS` 或 `T∘S` 的作用顺序。
- 识别恒等变换和零变换。
- 理解结合律和通常不交换。
- 理解可逆线性变换及逆变换的唯一性。
- 区分“变换之和”与“先后复合”。

## 页面讲解顺序

### 1. 起点问题：相加与先后执行不是一回事

给同一个向量 `x`：

- 左侧分别计算 `T(x)` 与 `S(x)`，再做向量相加。
- 右侧先做 `S` 再做 `T`。

用两个明显不同的终点提出问题。

### 2. 交互：Operator Mixer（算子混合器）

四个模式共享同一对变换和同一输入对象：

1. `T+S`：显示 `T(x)+S(x)` 的平行四边形。
2. `cT`：调节 `c`，观察输出向量缩放。
3. `T∘S`：连续播放 `x -> Sx -> T(Sx)`。
4. `S∘T`：与上一模式同步对照。

预设：旋转+剪切、投影+旋转、缩放+反射。

### 3. 零变换与恒等变换

用极简动画展示：

- `0(x)=0`。
- `I(x)=x`。
- `T+0=T`。
- `TI=IT=T`。

### 4. 复合保持线性

不给长证明；用公式逐步替换一次加法和一次数乘，再把证明折叠为可展开内容。

### 5. 可逆与逆序

同一对象执行 `S`、`T` 后，撤销必须先撤销 `T`，再撤销 `S`：

```text
(TS)^(-1)=S^(-1)T^(-1)
```

这里调用第四章逆矩阵知识，但不重复第四章完整求逆交互。

## 代表例题

设 `T` 为横向拉伸，`S` 为剪切：

- 写出 `T+S` 对任意 `(x,y)` 的作用。
- 比较 `TS` 与 `ST`。
- 写出 `(TS)^(-1)` 的正确顺序。

## 自测范围

- `T+S` 的逐点定义。
- 复合顺序。
- 结合律与不可交换。
- 恒等变换和零变换。
- 可逆变换的逆。
- 哪些运算需要域、陪域匹配。

## 验收标准

- 加法模式和复合模式不能复用同一动画结果。
- `TS` 的界面必须明确右边先作用。
- 不重复第四章“矩阵乘法行乘列”的主交互。
- 不把所有线性变换都假设成可逆。

# §3 线性变换的矩阵

## 参考资料

- 精选参考 PDF：第 36-50 页。
- 原书物理页：361-374。
- 主要用途：标准基与非标准基、坐标表示、基矩阵、同一向量在不同基下的坐标。
- 参考局限：同一线性变换在域基和陪域基下的矩阵表示、相似变换公式须依教材系统讲解。

## 核心问题

> 线性变换本身没有变，为什么换一组基以后矩阵会变？

## 学习目标

- 从域的一组基和陪域的一组基构造变换矩阵。
- 解释矩阵第 `j` 列为什么是第 `j` 个域基向量像的陪域坐标。
- 区分向量、向量坐标和矩阵记录。
- 理解同一个变换在不同基下有不同矩阵。
- 在同一空间换基时理解 `A'=P^(-1)AP`。
- 处理不同维数域与陪域的非方阵表示。

## 页面讲解顺序

### 1. 开场：对象不动，只换坐标语言

空间中的向量和箭头保持完全不动，坐标网格从标准基连续变成斜基；旁边的坐标列向量发生变化。

**媒介**：建议制作 2-3 分钟概念短片。

### 2. 自动动画：逐列建矩阵

给域基 `B=(v1,...,vn)` 与陪域基 `C=(w1,...,wm)`：

1. 依次送入 `v1,...,vn`。
2. 得到 `T(vj)`。
3. 在陪域基 `C` 中读取坐标。
4. 把坐标列依次放入矩阵。

最终得到 `[T]_{C<-B}`。

### 3. 主交互：Basis Translator（换基翻译器）

三栏布局：

- 左：真实空间与真实变换。
- 中：域基、陪域基控制。
- 右：输入坐标、输出坐标与变换矩阵。

学生拖动基向量时：

- 真实变换保持不变。
- 坐标数字和矩阵连续更新。
- 当基向量趋于共线时，显示“这不再是一组基”，禁止继续计算逆矩阵。

预设：标准基、斜基、缩放基、交换顺序的基、`R2 -> R3` 嵌入。

### 4. 同一空间换基与相似

用“旧坐标 -> 真实变换 -> 新坐标”的三段管线解释：

```text
A'=P^(-1)AP
```

矩阵发生变化，但变换的几何行为、特征多项式等内在性质不随基改变。

### 5. 非方阵表示

展示 `T:R2->R3` 和 `T:R3->R2`，明确矩阵形状由陪域维数乘域维数决定。

## 代表例题

给定 `T(x,y)=(x+2y,y)`，域基 `B=((1,1),(1,-1))`，陪域使用标准基：

- 求 `[T]_{E<-B}`。
- 再把陪域也换为 `B`，求 `[T]_B`。
- 解释两矩阵为何不同但描述同一变换。

## 自测范围

- 矩阵列的来源。
- 域基与陪域基。
- 非方阵尺寸。
- 换基矩阵的方向。
- 相似矩阵表达同一算子。
- 基退化时为什么公式失效。

## 验收标准

- 任何时候都能辨认“真实向量”和“坐标列”。
- 换基动画不得让真实几何变换跟着改变。
- `P` 与 `P^(-1)` 的作用方向必须由可见坐标管线验证。
- 本节不提前把换基简化为特征基；特征基放在 §5。

# §4 特征值与特征向量

## 参考资料

- 精选参考 PDF：第 51-61 页。
- 原书物理页：628-637。
- 主要用途：特征方向、特征值伸缩、单位圆到椭圆、特征方程与特征分解入口。

## 核心问题

> 一个变换作用以后，哪些非零方向仍然留在原来的直线上？

## 学习目标

- 理解 `Tv=lambda v` 中向量与标量各自的含义。
- 区分特征向量、特征方向和特征子空间。
- 用 `(T-lambda I)v=0` 连接特征值与核。
- 理解特征值的正负、大小和零值对应的几何行为。
- 求解简单矩阵的特征值与特征向量。
- 识别实数域上可能没有实特征向量的情况。

## 页面讲解顺序

### 1. 主动画：方向扫描器

在单位圆上均匀放置方向向量，施加同一个线性变换：

- 大多数方向发生转向。
- 特征方向经过变换后仍落在原直线上。
- 正特征值保持朝向，负特征值反向，零特征值被压到原点。

### 2. 主交互：Eigen Direction Scanner

学生拖动单位向量方向角，界面实时显示：

- `v` 与 `Av`。
- 二者夹角。
- 最佳标量 `lambda`。
- 残差 `||Av-lambda v||`。

真正特征方向处残差归零并吸附。预设：双特征方向、单一特征方向、重特征值、纯旋转、投影。

### 3. 从几何落回方程

把 `Av=lambda v` 移项为 `(A-lambda I)v=0`，调用 §6 的核概念只作预告：非零解存在意味着 `A-lambda I` 不可逆。

### 4. 特征多项式

展示 `det(A-lambda I)=0` 如何寻找候选特征值。二维例子采用可视化面积坍缩：调节 `lambda`，直到 `(A-lambda I)` 把平面压扁。

### 5. 特征子空间

对固定 `lambda`，所有特征向量再加零向量构成 `ker(A-lambda I)`。强调“单个特征向量”与“特征子空间”不是同一对象。

## 代表例题

使用一个剪切矩阵和一个旋转矩阵：

- 求实特征值与特征向量。
- 判断特征方向数量。
- 解释旋转矩阵在实数域上为何可能没有特征方向。

## 自测范围

- 零向量为什么不是特征向量。
- 特征值为零的含义。
- 负特征值的几何意义。
- `(A-lambda I)v=0`。
- 特征子空间。
- 数域对特征值存在性的影响。

## 验收标准

- 扫描器用残差判断，不能只靠角度近似。
- 纯旋转预设在实数域上明确显示“无实特征方向”，不错误吸附。
- 重特征值不等于自动拥有足够多特征向量。
- 本节不提前宣称所有矩阵均可对角化。

# §5 对角矩阵

## 参考资料

- 精选参考 PDF：第 62-77 页。
- 原书物理页：640-654。
- 主要用途：谱分解、特征基、正交特征向量、独立方向缩放、矩阵幂和低秩分解视角。
- 参考局限：参考页偏重对称矩阵；一般可对角化条件和非对称案例必须依据教材补齐。

## 核心问题

> 为什么找到一组足够多的特征向量以后，复杂变换会变成各坐标轴上的独立缩放？

## 学习目标

- 理解对角矩阵对各坐标分量独立缩放。
- 解释特征向量组成的基为何把矩阵化为对角矩阵。
- 理解 `A=PDP^(-1)` 的三步作用。
- 掌握可对角化的基本判据：存在一组特征向量基。
- 用对角化计算矩阵幂和多项式。
- 区分“有 n 个特征值”与“有 n 个线性无关特征向量”。

## 页面讲解顺序

### 1. 对角矩阵先行

先不谈对角化，直接展示：

```text
D(x1,...,xn)=(lambda1 x1,...,lambdan xn)
```

每条坐标轴独立伸缩，不发生方向混合。

### 2. 概念短片：换到特征基

建议 2 分钟：

1. 在标准基中，网格被复杂拉伸和剪切。
2. 找到两条特征方向。
3. 把坐标轴旋到特征方向上。
4. 同一变换在新坐标中只剩独立缩放。
5. 回到公式 `A=PDP^(-1)`。

### 3. 主交互：Diagonalization Workbench

三个连续阶段：

- `P^(-1)`：把旧坐标翻译成特征基坐标。
- `D`：沿特征轴独立缩放。
- `P`：翻译回原坐标。

学生可以切换：可对角化矩阵、重特征值但可对角化、特征向量不足、对称矩阵。

### 4. 为什么有时失败

如果特征向量不能组成一组基，`P` 不可逆，三段管线在第一步就失效。这里为 §8 Jordan 标准形引出问题。

### 5. 矩阵幂与多项式

对角化后：

```text
A^k=PD^kP^(-1)
```

用滑块改变 `k`，观察各特征方向按 `lambda_i^k` 演化。连接 §9 最小多项式，但暂不讲消去多项式。

## 代表例题

给一个具有两个独立特征方向的二维矩阵：

- 求 `P,D`。
- 验证 `A=PDP^(-1)`。
- 计算 `A^10x`。
- 用几何语言解释长期行为由哪个特征值主导。

## 自测范围

- 对角矩阵的作用。
- 对角化三步顺序。
- 可对角化条件。
- 重特征值与特征向量数量。
- 矩阵幂。
- 对称矩阵与正交对角化只作为特殊情形。

## 验收标准

- 对角化交互必须保持“同一变换、不同坐标”的语义。
- 失败预设明确显示 `P` 不可逆，而不是显示动画错误。
- 不把谱分解等同于所有矩阵的普通对角化。
- 本节结尾自然提出：特征向量不足时还能怎样组织结构？

# §6 线性变换的值域与核

## 参考资料

- 精选参考 PDF：第 78-103 页。
- 原书物理页：393-408、482-490。
- 主要用途：列向量线性组合、线性方程组的可达性、投影、输出空间、丢失方向和多解结构。

## 核心问题

> 一个线性变换能到达哪些向量？哪些输入会被完全压成零？

## 学习目标

- 定义并识别 `im T` 与 `ker T`。
- 理解值域是所有可能输出的集合。
- 理解核是被映到零向量的输入集合。
- 证明值域和核是子空间。
- 把值域与列空间、核与齐次方程联系起来。
- 理解秩-零度定理。
- 用核判断单射，用值域判断满射。

## 页面讲解顺序

### 1. 双空间舞台

左侧输入空间，右侧输出空间：

- 所有输入经过 `T` 汇入右侧的值域。
- 核中的输入使用一条特殊通道全部落到输出原点。

### 2. 主交互：Kernel-Image Lab

预设：

- `R2 -> R2` 可逆变换。
- 投影到一条直线。
- 零变换。
- `R3 -> R2` 投影。
- `R2 -> R3` 嵌入。

学生拖动输入向量，界面同步显示：

- 输入分解为“核方向部分 + 其余部分”。
- 输出向量。
- 核和值域的维数。
- 单射/满射状态。

### 3. 值域就是列空间

在选定基后逐列显示 `T(e_j)`；任意输出是这些列的线性组合。调用第四章列空间直觉，但把结论放回抽象变换。

### 4. 核就是齐次方程解空间

显示 `Ax=0` 的所有解形成直线、平面或零子空间。强调核位于输入空间，值域位于输出空间。

### 5. 秩-零度定理

使用“输入维数预算条”：

```text
dim V = dim ker T + dim im T
```

参数改变导致核变大时，值域相应缩小。该动画只表达维数关系，不暗示两个子空间天然正交。

### 6. 单射与满射

- `ker T={0}` 等价于单射。
- `im T=W` 等价于满射。
- 有限维同维空间中二者与可逆性联系起来。

## 代表例题

给定 `T:R3->R2`：

```text
T(x,y,z)=(x+z,y+z)
```

求核、值域、秩和零度，并判断单射与满射。

## 自测范围

- 核和值域所在空间。
- 列空间与值域。
- 齐次解空间与核。
- 秩-零度。
- 单射、满射、可逆。
- 零变换、投影、嵌入。

## 验收标准

- 核和值域必须分别画在输入与输出空间中。
- 维数预算条在所有预设中正确。
- 不把核与值域误画为同一空间中的互补或正交子空间。
- 投影预设能清楚显示不同输入拥有同一输出。

# §7 不变子空间

## 参考资料

- 精选参考 PDF：第 104-119 页。
- 原书物理页：438-445、492-498。
- 主要用途：坐标轴缩放、镜像轴、法向方向，以及子空间在变换后留在自身内部的特殊实例。
- 参考局限：参考书没有系统讲一般不变子空间；定义、闭包性质和限制变换必须依据教材原创组织。

## 核心问题

> 一个子空间经过线性变换后，什么时候仍然留在自己内部？

## 学习目标

- 定义 `T(W) subseteq W`。
- 区分“每个向量不动”“子空间整体不变”和“子空间中的向量仍留在其中”。
- 识别特征直线、核、值域等常见不变子空间。
- 理解限制变换 `T|_W`。
- 判断给定直线或平面是否不变。
- 理解不变子空间是分块化、对角化和 Jordan 理论的结构入口。

## 页面讲解顺序

### 1. 起点对照

同一条直线 `W`：

- 一个变换把直线送回自身，但线上点会移动。
- 另一个变换把直线转到别处。

先消除“不变就是逐点固定”的误解。

### 2. 主交互：Invariant Subspace Gate

学生选择候选直线或平面 `W`，界面随机采样多个向量并计算 `T(w)`：

- 若全部留在 `W` 内，绿色边界闭合。
- 若存在一个离开 `W` 的向量，显示反例和偏离分量。

预设：对角缩放、剪切、投影、镜像、旋转、三维上三角矩阵。

### 3. 特征直线只是第一类例子

一维不变子空间通常由特征向量张成；但高维不变子空间并不要求每个向量都是特征向量。

### 4. 核和值域是不变的吗

- `ker T` 对 `T` 总是不变。
- `im T` 对 `T` 也不变，因为 `T(im T) subseteq im T`。

用 §6 的视觉对象直接复用，不重新制作另一套核/值域实验。

### 5. 限制变换与分块结构

当 `W` 不变时，选择先列出 `W` 的基，再补成全空间基，矩阵出现上三角分块结构。这里只给结构预告，不进入完整 Jordan 证明。

## 代表例题

给定一个三阶上三角矩阵，判断：

- `span(e1)` 是否不变。
- `span(e1,e2)` 是否不变。
- `span(e2)` 是否不变。

要求学生用“任取向量并作用”与“看矩阵列”两种方法解释。

## 自测范围

- 不变子空间定义。
- 不变与逐点固定的区别。
- 特征直线。
- 核和值域。
- 上三角矩阵的标准旗标。
- 限制变换。

## 验收标准

- 交互必须给出实际反例向量，不能只打叉。
- 高维不变子空间不能被错误等同于“由同一特征值的特征向量组成”。
- 本节结尾明确连接：不变子空间可以把复杂变换拆成较小问题。

# §8 若尔当（Jordan）标准形介绍

## 参考资料

- 精选参考 PDF：第 120-133 页。
- 原书物理页：655-667。
- 主要用途：非对称矩阵的特征分解、不同几何行为和可对角化失败的动机。
- 参考局限：原书没有系统讲广义特征向量、Jordan 链和 Jordan 块；核心视觉与文案必须原创。

## 核心问题

> 当特征向量不足以组成一组基时，缺失的方向怎样被组织起来？

## 学习目标

- 理解可对角化失败的根本问题是特征向量不足。
- 定义广义特征向量的基本关系。
- 理解 Jordan 链的顺序。
- 理解 Jordan 块 `J=lambda I+N`。
- 认识幂零部分 `N` 在链上逐级传递的作用。
- 知道 Jordan 标准形的存在需要相应数域与分裂条件。
- 本节只作结构介绍，不要求完整证明唯一性。

## 页面讲解顺序

### 1. 从失败开始

选择一个只有一条特征方向的二维剪切型矩阵：

- 特征值重复。
- 特征子空间只有一维。
- `P` 无法由两条独立特征向量组成。

### 2. 概念短片：特征方向后面的“尾巴”

建议 3 分钟：

1. 先找到特征向量 `v1`。
2. 寻找 `v2`，使 `(T-lambda I)v2=v1`。
3. `v2` 不是特征向量，但它在减去主缩放后落到 `v1`。
4. 继续得到链 `v1,v2,...,vk`。
5. 在这组链基中，矩阵成为 Jordan 块。

### 3. 主交互：Jordan Chain Conveyor

显示链：

```text
v_k -> v_{k-1} -> ... -> v_2 -> v_1 -> 0
```

这里箭头表示 `N=T-lambda I`。学生可以：

- 调节 `lambda`。
- 选择 2 阶、3 阶 Jordan 块。
- 逐步作用 `T`、`N`、`N^2`。
- 观察链长与幂零指数。

### 4. `J=lambda I+N`

将统一缩放 `lambda I` 与链上位移 `N` 分层播放。避免把超对角线上的 `1` 解释成普通空间中的“向右移动”。

### 5. 多个 Jordan 块

用多个独立传送带并排组成整个空间，说明每个块对应一条链。只展示结构，不进入块排列唯一性的完整证明。

### 6. 与不变子空间的连接

每条链张成的子空间对 `T` 不变；多个块给出不变子空间的直和分解。这里可以埋下最小多项式和最大块长度的联系。

## 代表例题

给定 `J=[[lambda,1],[0,lambda]]`：

- 找特征向量。
- 找一个广义特征向量。
- 计算 `(J-lambda I)^2`。
- 解释为什么它不可对角化但具有一条长度 2 的 Jordan 链。

## 自测范围

- 特征向量不足。
- 广义特征向量。
- Jordan 链方向。
- `J=lambda I+N`。
- 幂零指数。
- 多个 Jordan 块与不变子空间。

## 验收标准

- 不用“差一个特征向量就随便补一个向量”的错误表述。
- 链关系的箭头方向和矩阵超对角线约定保持一致。
- 明确区分 `T` 的作用与 `N=T-lambda I` 的作用。
- 不在“介绍”小节中塞入完整 Jordan 标准形证明和所有算法细节。

# §9 最小多项式

## 参考资料

- 精选参考 PDF：第 134-145 页。
- 原书物理页：846-856。
- 主要用途：同一矩阵重复作用、矩阵幂、状态轨道和高次作用最终呈现有限结构。
- 参考局限：原书没有最小多项式理论；本节的定义、整除关系和 Jordan 联系必须原创并按教材校对。

## 核心问题

> 一个线性变换满足许多多项式方程，其中次数最低的那个怎样概括它的全部代数约束？

## 学习目标

- 理解多项式可以代入线性变换或矩阵。
- 定义消去多项式与最小多项式。
- 理解最小多项式存在且唯一首一。
- 理解最小多项式整除所有消去多项式。
- 连接 Cayley-Hamilton：`m_T` 整除特征多项式。
- 用最小多项式降低高次幂。
- 理解对角化与无重根条件的关系（在多项式分裂的假设下）。
- 理解 Jordan 块大小决定对应因子的最高次数。

## 页面讲解顺序

### 1. 从向量轨道开始

固定向量 `v`，依次显示：

```text
v, Tv, T^2v, T^3v, ...
```

在有限维空间中，轨道向量最终线性相关，于是某个多项式 `p` 满足 `p(T)v=0`。

### 2. 主交互：Polynomial Annihilator Lab

学生输入多项式系数，界面显示：

- `p(T)` 的矩阵。
- `p(T)` 对若干基向量的作用。
- 是否把整个空间都映到零。
- 多项式次数和是否首一。

预设：对角矩阵、单个 Jordan 块、两个不同 Jordan 块、投影、幂零矩阵。

### 3. 从局部消去到全局消去

区分：

- 只消去一个向量的多项式。
- 消去某个循环子空间的多项式。
- 消去整个变换的多项式。

最小多项式是全局条件，不由单个任意向量自动决定。

### 4. 最低次数与整除

通过多项式除法动画说明：若 `m_T(T)=0` 且 `p(T)=0`，则 `m_T` 整除 `p`。公式证明放在可展开区域。

### 5. 与特征多项式的关系

调用 Cayley-Hamilton：特征多项式一定消去 `T`，所以最小多项式整除特征多项式。这里不重新证明 Cayley-Hamilton。

### 6. 与对角化和 Jordan 块的关系

- 对角矩阵的最小多项式只包含出现过的不同特征值因子。
- 若最小多项式分裂且无重根，则变换可对角化。
- Jordan 块大小决定 `(x-lambda)` 的最高指数。

用 §8 的 Jordan 传送带直接复用视觉组件。

### 7. 降低高次幂

若 `m_T(x)=x^2-3x+2`，则：

```text
T^2=3T-2I
```

所有更高次幂都可化为 `I,T` 的线性组合。连接参考 PDF 中重复状态演化的计算需求。

## 代表例题

分别求下列矩阵的最小多项式并判断可对角化性：

- `diag(2,2,3)`。
- `[[2,1],[0,2]]`。
- 一个满足 `A^2=A` 的投影矩阵。

解析必须比较特征多项式、候选最小多项式和实际消去结果。

## 自测范围

- 多项式代入算子。
- 首一和最低次数。
- 消去一个向量与消去整个空间。
- 与特征多项式的整除关系。
- 投影、幂零矩阵、对角矩阵的最小多项式。
- 无重根与对角化。
- Jordan 最大块大小。

## 验收标准

- “最小”明确指次数最低，不是系数最小或数值最小。
- 交互必须检查 `p(T)` 是否为零算子，而不是只检查一个测试向量。
- 对角化判据必须注明分裂条件。
- 不把特征多项式和最小多项式当成总是相等。
- 不扩展到有理标准形、不变因子整除链或 PID 模结构定理。
