## 制作原则

- 数值线性代数统一使用精确有理数，不能以浮点阈值代替严格的秩、相关或有解判定。
- Canvas 只承担几何观察。高维判定必须使用完整坐标，投影必须明确标注。
- 每个实验回答一个可操作问题，并提供稳定预设、重置、必要的撤销和清晰状态反馈。
- 例题先让学生选择，再展开完整分析；错误选项不能提前泄露答案。
- 学生页面不出现制作进度、占位模块或内部参考资料说明。
- 交互监听器在离开小节时全部清理；Canvas 按设备像素比绘制。
