# 第六章制作矩阵

> 内部制作与验收记录。学生页面不展示本文件。
> 参考：`docs/ch6-teaching-blueprint.md`、六本经典线性代数教材，以及第四章第一节已经成熟的几何可视化语言。

## 全章教学主线

```text
集合与映射
→ 集合、数域、加法与数乘
→ 张成与相关性引理
→ 基的唯一表示与所有基等长
→ 用维数和坐标编码向量
→ 换基时区分对象与表示
→ 用线性组合判定子空间
→ 用基算法计算交、和与维数
→ 用直和获得唯一分解和补空间
→ 把基映到基构造同构
```

## 本轮重构原则

旧版本的问题不是缺少按钮，而是没有统一、可信的数学视觉语言。本轮按第四章成熟页面重新规定：

1. **向量必须是一体化的箭身与明确箭头头部**，粗细与第四章一致，不能再表现为圆点连接一根细线。
2. **几何量直接画出来**：张成范围用直线、网格或平面表示；二维无关性用平行四边形面积表示。
3. **主题服从全站**：只使用项目已有的表面、边框、文字、强调与反例变量，不建立第六章私有色板。
4. **对象按角色命名**：直接标注 `U`、`W`、`u`、`w`、`v`、输入与输出；颜色只辅助区分，不能代替说明。
5. **只有数学变化才动画**：§3 向量旋转与面积展开、§4 基变换连续插值；删除无教学意义的整块淡入动画。
6. **单一阅读轴**：观察目标 → 控件 → 全宽主视觉 → 数学判定 → 操作核对。

## 数学边界

- RGB 颜色立方体不是实数域上的线性空间。
- 纯换基中几何向量固定；主动线性变换才移动向量。
- 子空间必须含零并对任意线性组合封闭；不过原点的直线、平面属于仿射集合。
- `U+W={u+w}`，一般不等于 `U∪W`。
- 直和要求覆盖与零交，等价于唯一分解；不要求正交。
- 有限维同数域空间同构当且仅当维数相同；具体映射仍须线性且双射。
- 三个以上子空间的直和必须检查零向量只有平凡分解；两两交为零不足以替代这一条件。
- 正式讲解由 `current/content/ch6-section*.js` 单点维护，展示层不得再维护第二套正文。

## 浏览器验收线

真实 Chromium 必须同时检查行为与视觉几何：

1. 八节路由、正式内容、交互、例题、自测与小结完整。
2. 不得出现旧通用三栏卡片、左右不等高实验布局或“先看颜色图例”的教学方式。
3. 行内公式不得竖排碎裂；多项式变换的两条完整公式必须可读。
4. 所有二维向量使用填充箭头；普通原点圆点不得成为向量符号的一部分。
5. 同一 SVG 内标签不得互相覆盖或超出视口。
6. §3 从共线到独立时，面积、维数和判定同步变化；动画结束后控件仍可操作。
7. §4 预设切换连续变化；被动模式固定几何向量 `v`；主动模式不显示过渡矩阵。
8. §6 只解释公共方向与合成范围；§7 才解释分解存在性和唯一性，两节不得复用同一主画面。
9. 桌面亮色、桌面暗色、手机亮色、手机暗色与手机减少动态效果无控制台错误和页面级横向溢出。
10. 每轮 CI 保存完整页面与关键状态截图，必须人工逐页复核。
11. 回归打开第四章第一节，既有画布与例题保持正常。
