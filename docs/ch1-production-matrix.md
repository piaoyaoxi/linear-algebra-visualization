# 第一章多项式：制作与验收矩阵

> 范围：北大版《高等代数》第一章 §1—§11。  
> 目标：教材负责定义、定理和证明边界；网站负责展示运算过程、结构对应、临界状态与可核验结论。

## 本轮修复原则

1. 数学公式必须作为连续表达式呈现，不能把每个数字、符号或多项式片段包成独立圆角卡片。
2. 多项式长除法必须使用标准竖式结构：除式在左、被除式在括号内、商在横线上方、乘回结果在下方按同次项对齐。
3. 动画只表现真实运算过程：商项出现、乘回结果下移、相减线展开、余式出现。
4. 欧几里得算法、Bézout 代回、重因式公式与 Horner 账本均使用连续 KaTeX 表达式；较长公式允许横向滚动，但不得纵向碎裂。
5. 保留项目既有亮色与暗色主题，不新增深色霓虹舞台或无数学含义的装饰箭头。

## 重点修复

### §3 多项式整除

已删除旧的“一个系数一个框”展示，改为完整标准长除法：

- 商写在除法横线上方；
- 除式位于左侧；
- 被除式及每轮余式按次数列对齐；
- 新商项出现后，其与除式的乘积连续下移；
- 相减线逐步展开；
- 新余式随后出现并进入下一轮；
- 支持上一步、下一步、自动播放、重置以及整除、非整除、分数系数示例；
- 全过程同步保持 `f=qg+r`。

### §4 欧几里得算法与 Bézout 证书

- 修复账本中直接显示 `x^{4}` 等原始 LaTeX 的问题；
- 每轮除法等式作为完整公式显示；
- `s(x)`、`t(x)` 和最终代回验证不再拆成多个绿色小框；
- 最后一个非零余式与 Bézout 证书形成清楚的左右对应。

### §6 重因式

`f`、`f'`、`gcd(f,f')` 改为纵向连续公式行，取消狭窄卡片中的强制换行。

### §7 Horner 评价

每一步恢复为一条完整算术式，不再给每个中间数字单独套框。
