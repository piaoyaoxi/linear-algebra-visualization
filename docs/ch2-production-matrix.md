# 第二章“行列式”制作矩阵

> 对应 PR #35。学生页面严格沿北大版《高等代数》第二章 §1—§8 展开。视觉方案参考 `chapter2-visualization-production-blueprint.md` 与精选参考页，但所有前台图形、文案与交互均为原创实现。

## 全章主线

行列式是线性变换的有向体积倍率：

- `|det|` 记录面积或体积倍率；
- 符号记录定向是否翻转；
- `det=0` 记录维度塌缩；
- 排列奇偶性解释高阶展开项的符号；
- 分别线性与交替性生成计算规则；
- 余子式、克拉默法则、Laplace 定理与乘法规则把定义连接到计算、方程组与复合变换。

## 统一交互规则

1. 每个实验先写“观察任务”，再给自由操作。
2. 数值、公式、图形、符号与结论在同一帧更新。
3. `det>0`、`det<0`、`det=0` 同时使用文字、符号和图形表达，不依赖颜色单独传递信息。
4. 全部按钮使用原生语义控件；矩阵格使用按钮而非裸 `td` 作为交互目标。
5. Canvas 支持高 DPI，窄屏改为上下排列，`prefers-reduced-motion` 下关闭非必要动画。
6. 小节切换时销毁窗口级监听器与动画帧，避免重复挂载。
7. 例题继续复用统一 `example-challenge` 组件，题目先显示，解析在学生作答后展开。
