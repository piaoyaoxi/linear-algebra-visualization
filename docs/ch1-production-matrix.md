## 共享工程

- 精确数：`current/visuals/ch1/poly-math.js`
  - 整数、小数、分数字符串统一转为约分有理数。
  - 除零直接报错，不把非法结果吞成 0。
  - 多项式除法、gcd、扩展 Euclid、插值均使用精确有理数。
- 生命周期：`current/visuals/ch1/registry.js`
  - 每次路由切换清理监听器、ResizeObserver 与播放定时器。
  - 不在 `paint()` 中重复绑定事件。
- Canvas
  - 固定世界坐标与固定舞台高度。
  - 主题或容器尺寸变化时重绘，不改变数学状态。
  - 根、曲线、复平面和格点由同一数据生成。
- 例题
  - 每节恰有一个正确选项。
  - 正确后至少 5 个推理步骤；错误不泄露解析。
- 无障碍与响应式
  - 所有操作有原生按钮/输入控件和可见焦点。
  - Canvas 结论同步在文字读数中出现。
  - 390px 无横向溢出；`prefers-reduced-motion` 下播放改为快速离散步进。
