# 第四章制作矩阵

> 内部制作表。用于决定每一节做什么、做到什么程度；不要直接展示在学生页面。
> 最后更新：2026-07-03

## 制作规则

- 学生页面只显示已经成立的内容：真实视频、真实交互、正文、例题、自测和小结。
- 短片可选。只有存在真实 `video.src` 或 `video.embed` 时，页面才显示“概念短讲”。
- 未来短片脚本放在 `videoPlan` 或文档中，不进入前台视频模块。
- 交互可选。只有学生能通过操作回答一个明确问题时，才保留交互。
- 第四章先做 §2 样板，再按依赖补 §3、§4、§6，最后处理 §5、§7。

## §2 样板验收线

§2 完成后，应当成为后续小节的模板，但后续小节不强制复制全部模块。

- 起点问题能说明“为什么乘法不是逐项乘”。
- `videoPlan` 有完整 1-3 分钟短片脚本，但没有真实视频源时前台不显示视频。
- 交互实验用同一组矩阵串起三种读法：复合、看列、行列公式。
- 定理概念同时给出尺寸条件、行列公式、单位矩阵、结合律和通常不可交换。
- 代表例题折叠显示，至少分 5 步：查尺寸、算 `AB`、算 `BA`、解释顺序、提炼结论。
- 自测覆盖尺寸、作用顺序、列解释、元素公式和不可交换。
- 小结包含本节主线、下一节连接和常见误区。
