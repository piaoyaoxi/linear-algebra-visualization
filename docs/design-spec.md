## 5 玻璃（只用于顶部三控件、搜索弹窗、手机侧栏）

- 亮：`rgba(250,247,240,.72)` · blur 14px saturate 120% · 边 `rgba(60,52,30,.12)` · 影 `0 4px 14px rgba(50,42,20,.06)`。
- 暗：`rgba(30,34,31,.62)` · 同上模糊 · 边 `rgba(255,255,255,.09)` · 影 `0 4px 14px rgba(0,0,0,.3)`。
- 弹窗 / 侧栏：不透明度 +8%，blur 18px，遮罩 `rgba(40,36,24,.16)` / `rgba(0,0,0,.35)`。

## 6 实验区布局规则

1. 顺序固定：标题 → 先预测（通栏）→ 画布 | 操作。
2. 左栏 = 画布 + 图注，决定高度；右栏拉伸到同高，两栏底边对齐。
3. 右栏顶部是一行按钮：主按钮占满剩余宽度，次按钮靠右；主按钮贴着预测框下方，选完就能按。
4. 读数卡 = 固定头（标签 + 当前关键值）+ 正文（顶对齐）+ 固定图例（贴底）。短内容的空白落在正文和图例之间；长内容在正文区内滚动，卡片不撑高。
5. 图例统一放在读数卡底部，画布内不放图例。
6. 宽度 < 900 时改为单栏：预测 → 画布 → 按钮 → 读数。

## 实现时的取舍（与设计稿不同处）

- 次按钮文字保留「连续 10 次」「回到 x₀」，不缩写成「×10」「重置」。
- 预测框状态必须与读数一致：读数已经推进（k>0）时，预测框显示揭晓结果。
- 画布变量定义在 `current/tokens.css`，名称与本表一致；实验外壳的 palette() 里对应 v1 / v2 / drag / image / subspace / axis / grid / gridMajor。

## 落地后的补充（#89）

- 每节开头的标题卡片：“光影纸面”——纸面底 + 右上淡松绿光 + 左下淡金光 + 上沿高光 + 很柔的阴影，左上角一段 56px 的松绿短线；亮暗一致。真正的毛玻璃仍只用于浮在上方的三个控件、搜索弹窗和手机侧栏。
- 读数卡只在剩余高度不到 120px 时拉伸到画布底边，否则保持自然高度（避免空框）。
- 手机（≤720px）上，换行的切换片改为独立的小圆钮。
- 选预测之前，实验的主按钮（`.is-primary`）不可用；拖动与切换预设仍可自由探索。自己管理步骤锁的实验给按钮加 `data-la-free`（如第九章施密特正交化）。
- 例题选项、自测展开、“停一下”、侧边栏当前小节按“组件状态”页实现。
