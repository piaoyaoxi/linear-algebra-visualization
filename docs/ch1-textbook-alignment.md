# 第一章教材对齐与重构说明

## 目标

第一章以“多项式的结构链”为主线，不再把 11 节写成彼此独立的定义卡片。学生先在交互中观察一个可追踪的不变量，再由定义、定理、证明主线和边界反例解释这个现象。正文均为针对本项目重新组织的原创表述，没有摘抄教材段落。

## 本地教材的实际覆盖

本轮逐本检查了 `Linear Algebra/` 中的六本教材。它们对第一章的作用并不相同：

- Hoffman–Kunze, *Linear Algebra*：覆盖最完整。第 1.1 节给出域与子域语境，第 4 章依次讨论多项式代数、Lagrange 插值、多项式理想和素因子分解，适合作为 §§1–5、§7 的结构骨架。
- Friedberg–Insel–Spence, *Linear Algebra*：正文早期把多项式作为形式对象和向量空间，Lagrange 插值强调“指定评价值唯一确定低次多项式”；附录补充多项式理论，适合支持 §§2–5、§7–8。
- Axler, *Linear Algebra Done Right*：对多项式的写法简洁，突出除法算法、零点、代数基本定理以及实、复系数分解，适合支持 §§2–3、§7–8 的叙述节奏。
- Strang, *Introduction to Linear Algebra* 与 *Linear Algebra and Learning from Data*：不系统讲本章的整除与唯一分解，但 Vandermonde/插值材料能为 §7 提供“评价条件形成线性系统”的应用视角，有限域材料也能支持“形式多项式与多项式函数需区分”的边界例子。
- Lay–Lay–McDonald, *Linear Algebra and Its Applications*：目录和正文没有形成可直接支撑本章 11 节的系统多项式理论，因此本轮不把它作为第一章的主要依据。

本地这些英文教材没有系统覆盖本项目的 §§9–11（有理系数多项式、多元多项式、对称多项式）。这三节保留项目所依据的高等代数课程范围，采用标准的 Gauss 引理、指数向量卷积和对称多项式最高项消去论证重新写作，不把未覆盖内容冒充为英文教材结论。

## 11 节的内容—可视化对齐

| 小节 | 教学核心 | 可视化承担的证据 | 理论回收 |
| --- | --- | --- | --- |
| §1 数域 | 先固定允许的系数与除法 | 四道封闭性门；同一多项式随域变化的系数与分解状态 | 子域判别、Q(√2) 求逆、相对不可约 |
| §2 一元多项式 | 多项式是有限支撑系数序列 | 同次位置对齐；固定 k 汇总 i+j=k 的全部贡献 | 形式相等、卷积、次数定理 |
| §3 整除 | 首项消去让次数下降 | 标准长除法逐行显示商项、乘回项、相减与不变量 | 除法定理的存在与唯一性 |
| §4 最大公因式 | 取余保留公共因式 | 余式链与 Bézout 系数同步更新 | gcd 不变量、扩展欧几里得算法 |
| §5 因式分解 | 路线可变，标准叶唯一 | 两条真实拆分路线分别生成、标准化并比较叶集合 | 存在性、不可约因式的素性、唯一性 |
| §6 重因式 | 导数把重数降低一次 | 重数、导数表、gcd、根轴和固定坐标曲线联动 | 导数消失阶数与平方自由判别 |
| §7 多项式函数 | 评价连接余式、根和插值 | Horner 账本；精确根数构造；Lagrange 基 | 余数定理、根数上界、插值存在唯一性 |
| §8 实复分解 | 实系数迫使非实根共轭配对 | 复平面共轭锁、根之和与根之积同步变化 | C 上完全分裂、R 上一次/二次终止 |
| §9 有理系数 | 把 Q[x] 的问题压回本原 Z[x] | 清分母与提内容；候选验证；Eisenstein 三条件 | Gauss 引理、有理根定理、判据单向性 |
| §10 多元多项式 | 指数向量是项的地址 | 支撑格点、齐次层、指数和、目标系数贡献账本 | 齐次分解与多元卷积 |
| §11 对称多项式 | 置换轨道与基本对称坐标 | 换位/循环对比、轨道生成、σ 改写、Vieta 工作台 | 基本定理的最高项消去与唯一性 |

## 本轮采用的质量约束

- 每节必须有一个明确问题、一项可操作实验、一个由实验通向理论的桥梁、核心定理、至少四步证明主线和一个能限制结论适用范围的反例。
- 可视化不能只重复公式；它必须显示定义中的操作、证明中的不变量或错误推理失败的具体位置。
- 代表例题始终先显示题目与选项，答案和分析只在学生作答后展开。
- 所有关于可约、不可约、根与因式的结论都写明或保留当前系数域语境。
- 用自动检查固定已修复的数学边界：Q(√2) 中 x²−√2 不可约、四次无有理根不足以判不可约、重数实验不发生意外根碰撞、奇次实多项式不能恰有零个实根。
