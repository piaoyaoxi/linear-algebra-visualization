## 第三轮问题复盘

本轮不是继续微调旧卡片，而是依据浏览器截图确认并修复三类结构性错误：

1. 旧交互采用左右不等高两栏，右侧状态区把整行撑高，左侧主画面下方形成大块死空白。
2. 线性空间公理使用“加法形成阿贝尔群”等超出当前教学任务的术语，妨碍学生直接理解八条规则。
3. 向量标签沿箭头尖端外推，负方向向量容易出现标签压线、尖端遮挡或贴近画布边缘。

## 版式与绘图复核

- 八节实验统一为单一阅读轴：观察目标 → 控件 → 全宽主画面 → 判定结果 → 操作核对。
- 浏览器脚本直接检查主画面宽度、控件与主画面的上下顺序，以及结果区是否仍和主画面并排。
- 所有共享向量标签改为箭身中段的垂直偏移，并限制在 SVG 视口内；脚本检查标签边界及其与箭头尖端的距离。
- 桌面亮色、桌面暗色、手机亮色、手机减少动态效果均无页面级横向溢出。
- 长公式位于独立公式容器；行内公式保持单行。
- 第四章第一节回归正常。
