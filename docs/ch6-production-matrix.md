# 第六章制作矩阵

> 内部制作与验收记录。学生页面不展示本文件。  
> 参考：`chapter6-visualization-production-blueprint.md` 与 97 页精选参考 PDF。参考资料只用于研究，不进入公开站点。

## 全章教学主线

```text
集合与映射
→ 在集合上规定加法与数乘
→ 用基、维数和坐标建立有限描述
→ 更换基但保持对象不变
→ 在大空间中识别子空间
→ 研究交、和与维数账本
→ 用覆盖与零交得到唯一分解
→ 用同构识别相同线性结构
```

## 本轮重构原因

旧版把八节都塞进同一个三栏概念卡和同一种仪表盘式交互中，产生了三类根本问题：

1. 窄卡片把 KaTeX 行内公式挤成竖排碎片，数学表达失去可读性。
2. 各节都使用“若干定义卡 + 若干指标”的同一模板，没有形成像第四章那样逐层推进的教学叙事。
3. 交互把控制项、状态与指标同时堆给学生，却没有明确告诉学生先看哪个对象、改变参数后应验证哪条结论。

因此本轮删除通用第六章 renderer 和旧 refinement workbench，改为八个独立的小节 presentation。每节均按以下结构重新组织：

```text
本节主问题
→ 逐层概念模块
→ 必要推导或反例
→ 一句话连接到交互
→ 交互中的“先看什么”
→ 少量可解释的状态切换
→ 动态结论与观察任务
```

## 分节制作矩阵

| 小节 | 正式内容的叙事主线 | 引导式交互 | 关键边界与修复 |
|---|---|---|---|
| §1 集合·映射 | 完整规则 → 像/原像/值域/陪域 → 单射/满射/双射 → 复合与逆 | 映射检查台：先合法，再检查输入碰撞与输出遗漏，最后显示逆映射 | 修复等势有限集无法构造“单射非满射”的逻辑矛盾；定义域与陪域大小可不同 |
| §2 线性空间定义 | 常见对象 → 八条公理分组 → 简单性质推导 → 最短反例策略 | 线性空间体检：零向量、加法、任意数乘三道检查；二维反例与真实三通道 RGB | RGB 明确使用 `[0,1]^3`；一个反例足以否定，有限次试验通过不替代证明 |
| §3 维数·基与坐标 | 张成回答“够不够” → 无关回答“是否冗余” → 基 → 维数与坐标 → 提取基 | 从三向量冗余生成组删到基；显示张成范围、有序基和目标坐标 | 修复旧版只有两个向量、无法真正执行“删冗余”的问题 |
| §4 基变换与坐标变换 | 同一向量不同坐标 → 基矩阵 → 过渡矩阵推导 → 主动/被动对照 → 基退化 | 同一画布上的两种“变”：被动模式固定向量，主动模式固定基；连续进度与退化终点 | 公式不再进入窄卡片；修正 `P_{W←U}=W^{-1}U`；主动模式不显示过渡矩阵 |
| §5 线性子空间 | 子空间定义 → 统一判定 → 原点筛查 → span/齐次解集 → 仿射平移 | 子空间过滤器：直线平移、齐次/非齐次平面、象限与多项式约束 | 强调过原点只是必要条件；统一使用线性组合判定 |
| §6 子空间的交与和 | 交空间 → 和空间与集合并区别 → 维数账本 → 基合并 → 精确例题 | `R²/R³/R⁴` 五类结构；图中直接标出公共方向与和空间维数 | 例题补出 `U∩W` 和 `U+W` 的具体基，而非只报维数 |
| §7 子空间的直和 | 覆盖闸门 → 零交闸门 → 唯一性证明 → 公共方向搬运 → 正交特例 | 四类对照：非正交直和、正交直和、覆盖但不唯一、零交但未覆盖 | 修复旧版“破坏唯一性”预设仍线性无关的 bug；存在与唯一分开检查 |
| §8 线性空间的同构 | 线性 + 双射 → 坐标同构 → `P₂≅R³` → 维数分类 → 同构/相等/等距区别 | 结构桥验收台：实际比较两条运算路径，并分别检查单射、满射 | 明确同维数只保证存在某个同构，不代表任意规则都是同构 |

## 全章硬规则

- RGB 颜色立方体不是实数域上的线性空间。
- 纯换基中几何向量固定；主动线性变换才移动向量。
- 子空间必须含零并对任意线性组合封闭；不过原点的直线、平面属于仿射集合。
- `U+W={u+w}`，一般不等于 `U∪W`。
- 直和要求覆盖与零交，等价于唯一分解；不要求正交。
- 有限维同数域空间同构当且仅当维数相同；具体映射仍须线性且双射。
- 没有真实视频源时只保留 `videoPlan`，学生页面不显示空视频模块。

- 内容：`current/content/ch6-section1.js`—`ch6-section8.js`，`ch6-refinement.js` 仅修正已经组装的例题、任务与小结数据。

- 共享工具：`shared-presentation.js` 只提供公式、模块、引导式实验、二维图形与矩阵运算基础，不决定具体小节结构。

- 已删除：旧通用 `section-presentation.js`、旧 `refinement.js` 与 `refinement.css`，避免两个渲染体系并存。
- 路由：通用结构化章节渲染器继续负责总览、分节、进度与前后导航。

## 浏览器验收线

真实 Chromium 必须同时检查行为和视觉几何：

1. `#ch6` 显示八张小节卡片，八节路由均可进入。
2. 每节存在独立 `.ch6-foundation`、多个教学模块、真实 `.ch6-guided-lab`、代表例题、自测与小结。
3. 页面不得再次出现旧 `.concept-strip` 通用三栏卡片。
4. 所有行内公式的实际高度不超过 48px，不允许出现逐字符竖排；长行间公式只在公式容器内横向滚动。
5. §1 不完整、单非满、满非单与双射四种状态的解释和判定正确。
6. §2 RGB 使用两行、每行三通道展示原向量与越界结果；仿射线与象限反例正确。
7. §3 冗余组三向量可删成基，交换基顺序后坐标改变。
8. §4 被动模式明确提示向量端点固定；退化终点拒绝基；主动模式不出现过渡矩阵。
9. §5 非齐次平面在零向量处失败，常数项为 0 的多项式集合通过。
10. §6 五类维数账本正确，两个平面案例显示 `2+2-1=3`。
11. §7 四个案例分别覆盖“覆盖/零交”的四种关键组合，公共方向参数产生多组分解。
12. §8 坐标同构通过；投影在单射处失败；平方规则在线性和满射处失败。
13. 亮色、暗色、`1440×1000`、`390×844`、`prefers-reduced-motion` 无控制台错误和页面级横向溢出。
14. 每次 CI 保存八节在四种视口/主题下的 32 张完整页面截图，供逐页人工复核。
15. 每节“观察任务”必须与实际存在的按钮、滑块和状态完全一致。
16. 回归打开 `#ch4/matrix-language`，第四章既有画布与例题仍正常。
