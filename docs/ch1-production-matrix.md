# 第一章多项式：制作与验收矩阵

> 范围：北大版《高等代数》第一章 §1—§11。  
> 目标：教材负责定义、定理和证明边界；网站负责展示运算过程、结构对应、临界状态与可核验结论。  
> 当前策略：不强制所有小节制作大型动画。只有当“连续变化过程”本身具有教学价值时，才使用 Canvas 或 SVG 动画；其余内容优先采用清晰的静态结构图、表格和短交互。

## 总体设计规则

1. 使用全站现有的亮色、暗色主题变量，不为第一章另造深色霓虹配色。
2. 动画只让数学对象移动，不使用没有数学含义的弯曲箭头、光效和装饰性粒子。
3. 每个实验必须明确回答一个问题，并形成“选择情境 → 操作 → 观察 → 数学结论”的闭环。
4. 精确判定使用有理数与多项式运算引擎，不以像素距离或浮点阈值替代整除、重根、互素等代数条件。
5. 没有必要的地方宁可使用普通静态图，不用为了显得高级而强行动画。

## 本轮重点：§3 连续长除法

旧版点击“下一步”后直接替换公式和系数带，学生看不到中间发生了什么。本轮把一次首项消去拆为连续过程：

1. 除式副本从原位置平移；
2. 商项决定水平位移与系数缩放；
3. 副本最高次项与当前余式最高次项对齐；
4. 同列相减，最高次项显示精确抵消；
5. 新余式从相减结果位置平滑上移，成为下一轮被除式。

同时提供上一步、下一步、自动播放和重置；`prefers-reduced-motion` 下保留离散步骤但不丢信息。

## 本轮重点：§8 共轭根几何

- 拖动 `α=a+bi` 时，`ᾱ=a-bi` 关于实轴连续镜像；
- 图中直接显示横坐标 `a`、虚部 `b` 与从原点到根的距离 `|α|`；
- 同步读取 `α+ᾱ=2a` 和 `αᾱ=|α|²`；
- 切到复系数模式后，第二个根可以独立移动，并明确显示系数虚部何时出现；
- 支持滑块、鼠标或触控拖动和键盘方向键。
